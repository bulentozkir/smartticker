# SmartTicker 帮助

本指南适用于 SmartTicker 1.0.3。它介绍主行情条、应用设置、
报价、警报规则、网站权限、备份以及常见问题。

SmartTicker 会读取您所配置网页中的公开静态 HTML。它不
提供市场数据源，提取的信息可能延迟、不完整或
有误。请通过权威来源核实重要的金融信息。

## 打开帮助和配置窗口

右键单击行情条以打开其菜单。主要配置命令如下：

- **报价... (Quotes...)**：添加、测试、编辑、排序和删除报价或新闻来源。
- **报价组... (Quote groups...)**：创建、更新或删除组，并将报价与组关联。
- **警报 (Alerts)**：创建和管理价格警报规则。
- **应用设置... (App Settings...)**：配置行数、速度、刷新间隔、启动、网站
	访问、颜色、透明度和备份。
- **视图 (View)**：选择四种互斥组合之一：滚动或静态，
	仅价格或价格与新闻。
- **帮助 (Help)**：在 SmartTicker 内打开本指南。
- **关于 SmartTicker (About SmartTicker)**：显示已安装版本和许可证声明。
- **退出 (Exit)**：完全关闭 SmartTicker。

“帮助”窗口会立即格式化并显示所选应用语言对应的内置指南，然后在您每次打开“帮助”
或更改 **语言 (Language)** 时检查相应语言的在线指南。中文在线指南为：

<https://raw.githubusercontent.com/bulentozkir/smartticker/refs/heads/main/help/HELPME.zh.md>

如果无法下载在线文档，SmartTicker 会继续显示相应的内置译文。更改 **语言 (Language)** 后，
已打开“帮助”窗口的标题、状态、导航和完整指南会立即更新。使用正常的标题栏关闭控件关闭“帮助”。

## 主行情条控件

### 选择滚动或静态报价视图

SmartTicker 提供四种互斥的显示模式。右键单击行情条，打开
**视图 (View)**，然后选择一种模式。布局会立即更改并保存您的选择。

| 视图选项 | 结果 |
| --- | --- |
| **从左到右滚动：仅价格 (Left-to-right scroll: Prices only)** | 主行情条中的价格跑马灯；不显示新闻。这是默认设置。 |
| **从左到右滚动：价格与新闻 (Left-to-right scroll: Prices with News)** | 主行情条中的价格和新闻跑马灯。 |
| **静态视图：仅价格 (Static view: Prices only)** | 主窗口中的响应式价格磁贴；无“新闻”窗口。 |
| **静态视图：价格与新闻 (Static view: Prices with News)** | 响应式价格磁贴，以及单独的静态 **SmartTicker News** 窗口。 |

在添加这些选项之前创建的设置文件，会按照其已保存的滚动/静态
和新闻设置映射到相应组合。显示模式只能通过行情条右键单击菜单中的
**视图 (View)** 进行管理。

- 在任一滚动模式中，价格都使用水平跑马灯以及已配置的价格行
	数和滚动速度。
- 在任一静态模式中，组都显示为从左到右排列的响应式磁贴。只有当窗口
  过窄时，磁贴才会换到下一行。价格不会
  自动移动。
- 每个报价磁贴都有自己对齐的 **代码 (Symbol)**、**最新价 (Last)**、**涨跌额 (Chg)** 和 **涨跌幅 (Chg%)**
  列。**涨跌额 (Chg)** 根据最新价和涨跌幅计算，
	因为来源页面提供的是百分比选择器，而不是单独的绝对涨跌额选择器。
	任一值不可用时，它会显示 `—`。
- 选择组标题可折叠或展开该组。各组按其报价在已配置条目顺序中
	首次出现的位置排列；组内各行保持该顺序。
- 未分组的条目显示在 **未分组 (Ungrouped)** 下。
- 将鼠标悬停在“最新价”上可查看可用的盘前和盘后值。双击
	报价行可打开其来源页面。
- 警报闪烁和上涨/下跌颜色在两种价格模式中均有效。
- 新闻会自动在单独的 **SmartTicker News** 窗口中打开，其中包含静态的
	**代码 / 标题 (Symbol / Headline)** 组磁贴。在静态模式中它不会滚动。“新闻”
	窗口具有正常的标题栏和调整大小边框，因此“报价”和“新闻”窗口可以
	分别移动到不同的显示器。双击标题行可打开其来源。
- 首次启动时，“新闻”使用紧凑的 680×340 大小。如果有其他显示器，SmartTicker
	会将它放到另一台显示器上；在单显示器上，它会先尝试“价格”下方、
	右侧、上方或左侧的空闲区域。之后您可以正常移动和调整其大小。
- 在每个“新闻”组内，标题按报价交错排列：先显示第一个报价的一条标题，
	再显示下一个报价的一条标题，如此循环。因此，拥有大量
	标题的报价不会占满其组的顶部。
- 打开单行 **显示以下项目的新闻 (Show news for)** 下拉列表，逐个独立选中或清除报价。
	任意报价组合都可见，包括全部或一个也不显示。按钮会概括当前选择，
	条目中包含报价和来源，因此重复代码仍相互独立。清除的报价会在设置文件中保存为
	`hiddenNewsQuotes`，因此重启后仍然有效，并随设置备份转移。
- 拖动任意报价或新闻磁贴标题旁的点状手柄，并将其放到另一个磁贴的左半边
	或右半边。两个窗口中的顺序都会改变，并通过重新排序底层
	已配置条目进行保存。
- 行数较多的组会在自身有界磁贴内滚动。只有当换行后的磁贴行
	无法放入当前窗口高度时，整体视图才会垂直滚动。

关闭 **SmartTicker News** 不会禁用新闻收集。要重新打开它，请右键单击
“价格”窗口并选择 **视图 > 打开静态新闻窗口 (View > Open static news window)**。选择 **静态
视图：仅价格 (Static view: Prices only)** 会将其关闭；选择 **静态视图：价格与新闻 (Static view: Prices with News)** 会再次
打开它。任一滚动选项都会关闭单独的“新闻”窗口；滚动的
“价格与新闻”选项会恢复主行情条中的新闻跑马灯。

切换模式时会应用为该视图保存的大小。滚动行情条、静态“价格”
窗口和静态“新闻”窗口各自保留独立的宽度和高度。

### 移动行情条

按住左侧窄条顶部的竖点手柄，拖动
行情条，然后松开鼠标按钮。行情条文本不是拖动区域，因此选择
或单击内容不会意外开始移动窗口。

### 调整行情条大小

将指针移到任意边缘或角落，直到出现调整大小光标，然后按住并
拖动。右下角有一个可见的小型调整大小标记。最小窗口宽度
为 420 像素。滚动视图高度为 50 至 900 像素，静态“价格”高度为 420
至 4320 像素，静态“新闻”高度为 240 至 4320 像素。

手动调整大小会在拖动稳定后更新活动视图保存的尺寸。
设置备份包含所有三组尺寸。窗口位置不会保存。
如果滚动视图大小对于所选“价格/新闻”行和滚动字体
大小而言过小，SmartTicker 会自动提高保存的高度。因此，选择 **从左到右
滚动：价格与新闻 (Left-to-right scroll: Prices with News)** 始终会为“新闻”行留出空间，而不会
悄悄隐藏它们。
每当窗口打开或移动时，SmartTicker 会确保其左上角至少有 32 像素
处于某个屏幕工作区内，并将全局 X 和 Y 限制为至少 1。这样，即使显示器断开连接，
仍可用鼠标触及移动手柄或标题角。

### 暂停和继续

选择移动手柄下方的状态按钮，或右键单击并选择
**暂停 / 继续 (Pause / Resume)**。暂停会停止自动价格和新闻刷新，并冻结
跑马灯。它还会阻止任一手动刷新命令启动新工作。仅因暂停操作，
已经进行中的来源请求不会被强制取消，并且可能在活动完全
稳定之前完成。继续会重新启动自动计时器。

在 Windows 上，SmartTicker 会在启动 UI 前自动将其操作系统进程优先级设为 **低 (Low)**，并启用
Windows **效率模式 (Efficiency mode)** (EcoQoS)。此行为没有应用设置。
它还使用低开销的软件渲染路径。跑马灯计时会适应
已配置的速度，而暂停、空白或已分离的跑马灯会停止其动画
计时器。未发生变化的行会抑制多余的视觉通知。警报闪烁和
三秒的棕色变更高亮是有意设计的，不会暂停滚动。Linux
进程调度由操作系统处理。如果 Windows 拒绝任一进程
设置，SmartTicker 会将失败写入诊断跟踪并继续启动。

### 打开链接

双击带链接的行情条文本（包括新闻标题），在默认
浏览器中打开其来源。SmartTicker 不会在单击时打开链接。

### 变更高亮

每次刷新后，SmartTicker 会用棕色背景短暂标记发生变化的内容，持续三秒：

- 价格与上一次同步不同的报价。
- 对于该报价，上一次同步中不存在的每条标题。

启动后的第一次同步不会高亮任何内容，因为没有先前值可供
比较。已触发的警报保留其自己的警报闪烁颜色并具有优先权。

行可见性、语言和其他配置值会自动保存。

## 报价

从右键单击菜单打开 **报价... (Quotes...)**。每个已配置条目代表一个
代码和一个网页。允许使用重复代码，而且由于每个条目都有自己的来源、
选择器、收集选项和警报，它们仍相互独立。

### 使用已发布示例快速开始

不存在条目时，“报价”窗口会提供 **从 GitHub 导入示例报价 (Import sample quotes from GitHub)**。
这会下载存储库示例，并替换当前应用设置。
使用前，请查看每个导入的 URL 以及各网站的当前条款。之后您可以
编辑或删除任何示例条目。

“报价”和“应用设置”窗口顶部的 **导入示例报价配置 (Import Sample Quotes Config)**
可随时执行相同操作，但会先要求确认：

- SmartTicker 会询问 **确定吗？(Are you sure?)**，并警告下载将替换现有的
	报价、报价组、来源批准、视图、外观及其他应用设置。
	警报规则位于自己的文件中，不会被删除。
- **导出现有配置... (Export existing config...)** 是可选操作。它会将当前配置保存到
	本地 JSON 文件，然后返回同一确认界面。
- **导入示例报价配置 (Import Sample Quotes Config)** 会从互联网下载示例并替换
	您的配置。
- **取消 (Cancel)** 不会更改任何内容。

### 添加报价或新闻条目

1. 输入 **行情代码 (Ticker)** 标签，例如 `MSFT`。SmartTicker 会去除首尾空格并以
	 大写形式存储。
2. 可选择从查找框中选择现有 **组 (Group)**，或输入新名称，例如
	 `Nasdaq`、`Precious Metals` 或 `Mag 7`。留空则归入 **未分组 (Ungrouped)**。
3. 选择一个 **来源 (Source)** 预设。
4. 输入 **URL 后缀 (URL suffix)**，使用 **自定义 URL (Custom URL)** 时则输入完整 URL。
5. 在 **收集 (Collect)** 下选择 **价格 (Price)**、**新闻 (News)** 或两者。至少需要选择一项。
6. 手动输入选择器、使用发现按钮，或将可选选择器
	 留空以使用内置检测。
7. 选择 **验证 URL (Validate URL)** 以测试正常价格和/或标题。
8. 如果 SmartTicker 请求来源批准，请查看网站，并仅在
	 您获准从该网站收集信息时确认。
9. 选择 **添加独立条目 (Add independent entry)**。SmartTicker 会保存该条目并立即刷新其
	 已启用的数据。

### 对报价分组

组是由您定义的命名集合。它不与交易所或内置
类别绑定，因此您可以按市场、资产类型、策略、投资组合、
地区或任何其他方案组织条目。名称会去除首尾空格，可使用 Unicode，最长为
80 个字符。每个报价最多只能属于一个组。

使用“组”字段旁的 **管理组 (Manage groups)**，或从行情条的
右键单击菜单选择 **报价组... (Quote groups...)**。窗口有三个工作区域：

- 在左侧输入 **组名 (Group name)**，然后选择 **创建 (Create)**。选择现有组，
	编辑其名称并选择 **更新 (Update)**，或选择 **删除 (Delete)**。空组会保留。
- 在右侧选择一个报价。其当前组显示在 **当前组 (Current group)**
	列中；**未分组 (Ungrouped)** 表示它没有关联。
- 在中间选择一个组和一个报价后，选择 **关联 (Associate)**。如果该
	报价已属于其他组，SmartTicker 会将其移到所选组。
- 选择 **删除关联 (Remove association)**，仅将所选报价返回 **未分组 (Ungrouped)**。
- 删除组会将其中所有报价返回 **未分组 (Ungrouped)**。报价、来源、当前
	数据和警报不会被删除。
- 添加或编辑报价时，也可以从查找框选择现有组，
	或在那里输入新组名。
- 使用“已配置条目”中的向上/向下控件确定静态表格中的组和行顺序。
- 在静态模式中，拖动磁贴标题可直接重新排序整个组。单独的
	“报价”和“新闻”窗口使用相同顺序。

已发布示例包含六个示例组，但默认保持静态模式关闭。
导入后启用静态视图，即可用表格查看这些组。

### 来源预设和 URL

| 来源 | 输入内容 | SmartTicker 显示的政策 |
| --- | --- | --- |
| **Yahoo Finance** | `https://finance.yahoo.com/` 之后的后缀，例如 `quote/MSFT/`。 | 需要书面许可。Yahoo 的条款禁止未经事先许可的自动收集。 |
| **CNBC** | `https://www.cnbc.com/` 之后的后缀。 | 检查网站当前政策和 robots 指令。 |
| **Trading Economics** | `https://tradingeconomics.com/` 之后的后缀。 | 优先使用有文档的 API 或授权数据源，并检查网站当前政策。 |
| **自定义 URL (Custom URL)** | 完整的公开 `http://` 或 `https://` 页面 URL。 | 查看网站的条款、隐私政策和自动访问规则。 |

只接受绝对 HTTP 和 HTTPS URL。包含嵌入用户名或
密码的 URL 会被拒绝。在浏览器中登录并不授权 SmartTicker 收集
页面，SmartTicker 也不会使用已认证的浏览器会话。

**完整 URL (Full URL)** 行显示由预设前缀和您的后缀生成的最终地址。
在验证或发现之前检查该地址。

### 收集选项

- **价格 (Price)** 请求正常价格。可选的涨跌、盘前和盘后
	选择器会在同一下载页面中求值。
- **新闻 (News)** 请求页面中的标题链接。
- 同时选择两者可让一个条目为两个行情条区域提供内容。
- 两者均清除属于无效配置。

### 选择器字段参考

CSS 选择器用于标识网页静态 HTML 中的元素。除非自动检测
无法找到您所需的值，否则选择器是可选的。

| 字段 | SmartTicker 提取的值 |
| --- | --- |
| **价格选择器 (Price selector)** | 正常价格或收盘价。 |
| **价格涨跌 (Price change)** | 正常交易时段的百分比变化。留空时会尝试内置涨跌检测。 |
| **盘前选择器 (Pre-market selector)** | 页面存在该交易时段时的盘前价格。 |
| **盘前涨跌 (Pre-market change)** | 盘前百分比变化。 |
| **盘后选择器 (After-hours selector)** | 收盘后或盘后价格。 |
| **盘后涨跌 (After-hours change)** | 收盘后或盘后百分比变化。 |
| **新闻选择器 (News selector)** | 标题链接。选择一个锚元素，或选择结果中包含链接的容器。 |

盘前和盘后值用于补充正常价格，而不会替代
正常价格。在相应市场交易时段之外，页面可能省略这些元素。

已发布示例使用的 Yahoo Finance 选择器如下：

```text
Price:                  [data-testid="qsp-price"]
Price change:           section.primary span[data-testid="qsp-price-change-percent"]
Pre-market price:       section.secondary span[data-testid="qsp-pre-price"]
Pre-market change:      section.secondary span[data-testid="qsp-pre-price-change-percent"]
After-hours price:      section.secondary span[data-testid="qsp-post-price"]
After-hours change:     section.secondary span[data-testid="qsp-post-price-change-percent"]
```

网站标记会随时间变化。请将示例视为起点，而不是永久
约定。

### 发现选择器

每个选择器字段都有对应的 **发现 (Discover)** 按钮。

1. 填写来源 URL，如果需要批准网站，请予以批准。
2. 选择与确切值类型对应的发现按钮。
3. SmartTicker 会下载公开静态 HTML，并列出可能的选择器，同时在工具提示中显示示例
	 值、置信百分比和原因。
4. 选择建议旁的 **使用 (Use)**，将其复制到匹配字段。
5. 在依赖结果之前，先进行验证或观察。

发现功能不会运行 JavaScript、登录、绕过访问控制或检查您的
浏览器。仅由 JavaScript 生成的值可能没有可发现的选择器。不同的发现
类型会有意避免混淆盘前值和盘后值。

### 验证来源

**验证 URL (Validate URL)** 会请求页面，并报告它能够读取的正常价格和/或
标题数量。由于 SmartTicker 使用临时标签进行测试，因此在输入行情代码前使用也很安全。

此验证目前不会检查四个盘前和盘后选择器
字段。请使用它们的发现示例值，然后确认显示的交易时段数据。

典型故障包括 HTTP 错误、超时、缺少值、零条标题、来源
权限未获批准、仅含 JavaScript 的内容或过时的选择器。

### 新闻重复次数限制

**最多显示 _N_ 次 (Show max _N_ times)** 接受 1 至 100，默认为 5。SmartTicker 会对每个已完成的
新闻刷新周期计数一次，只要该周期返回相同的标题文本。标题达到已配置的
周期次数后，会在当前应用会话的剩余时间内停用。编辑或删除该条目会清除
其重复历史记录。

### 编辑排序和删除条目

**已配置条目 (Configured entries)** 列表显示代码、组、来源、URL、收集徽章、
正常价格选择器、新闻选择器和新闻重复次数限制。

- **编辑 (Edit)** 将条目加载到表单中。选择 **保存更改 (Save changes)** 以应用，或选择
	**取消编辑 (Cancel edit)** 以放弃表单更改。
- 向上和向下箭头按钮会更改行情条顺序并立即保存。
- **删除 (Remove)** 会删除条目及其当前显示的数据。
- 如果警报规则以该条目为目标，SmartTicker 会询问是否删除这些规则。没有
	匹配已配置报价的警报无法触发。
- 重命名条目会更新附加到该条目的规则所显示的警报规则代码。

### 行情条行数和速度

| 设置 | 选项 | 默认值 | 效果 |
| --- | --- | --- | --- |
| 价格行数 | 1 至 8 | 1 | 并行价格跑马灯行数。 |
| 价格滚动速度 | 20、30、40、50、65、80、100 或 120 px/sec | 50 | 价格跑马灯速度。 |
| 新闻行数 | 1 至 8 | 1 | 并行标题跑马灯行数。 |
| 新闻滚动速度 | 20、30、40、50、65、80、100 或 120 px/sec | 40 | 新闻跑马灯速度。 |
| 滚动字体大小 | 9 至 24 pt | 14 pt | 滚动行中的价格和新闻文本。 |
| 静态字体大小 | 9 至 24 pt | 13 pt | 静态行中的报价和标题文本。 |
| 价格刷新 | 30 至 300 秒，以 15 秒为步长 | 60 秒 | 每个获准价格条目接收一次计划刷新所用的时间。 |
| 新闻刷新 | 30 至 300 秒，以 15 秒为步长 | 300 秒 | 每个获准新闻条目接收一次计划刷新所用的时间。 |

启用静态分组表格时，价格行数和价格滚动速度会被禁用，
因为该模式显示所有价格条目，并且两个窗口都不会自动滚动。
新闻行数和速度设置会保留供滚动视图使用。

价格和新闻请求会在各自完整间隔内独立分布到一秒时间槽中，
而不是同时开始。例如，30 秒内的 60 个条目会安排为每秒两个条目；
30 秒内的五个条目大约每六秒安排一个。最多同时运行四个来源请求，
同一条目和流的重复工作会被跳过，错过的时间槽不会集中突发重放。**立即
刷新价格 (Refresh prices now)** 或 **立即刷新新闻 (Refresh news now)** 只会重启相应流并请求其第一个时间槽。
读取替代数据期间，现有的成功价格和标题仍保持可见。

每个 HTTP 请求都有固定的 20 秒超时。缓慢的来源不会占用 UI
调度程序，也不会阻止后续时间槽使用剩余的请求容量。SmartTicker
会报告 HTTP 403 和 429 等故障，且不会绕过限制。它不会
自动解析或执行 robots 指令、crawl-delay 值或服务器退避指令，因此请选择合规来源，并避免
不必要的频繁请求。

### 登录时启动 SmartTicker

启用 **登录时启动 SmartTicker (Start SmartTicker when I sign in)**，仅为
当前用户注册已安装的可执行文件。

- 在 Windows 上，SmartTicker 使用当前用户的 `Run` 注册表项。
- 在支持 freedesktop 自动启动约定的 Linux 桌面上，SmartTicker
	会在用户的自动启动目录中写入 `smartticker.desktop`。
- 在 SmartTicker 没有受支持注册机制的平台上，该选项会被禁用。

操作系统是权威来源。如果在 SmartTicker 外部更改启动设置，
下次加载设置时，复选框会反映操作系统状态。

### 网站访问

**允许网站 Cookie 和跨主机重定向 (Allow website cookies and cross-host redirects)** 默认禁用。

禁用时：

- SmartTicker 在请求每个网站主机之前，需要对该主机进行一次明确批准。
- 不接受网站 Cookie。
- 阻止重定向到其他主机。
- 已批准的主机会记入本地设置。

启用时：

- SmartTicker 会跳过逐主机批准步骤。
- 所请求网站设置的 Cookie 仅保存在隔离的内存容器中，
	并在 SmartTicker 退出时消失。
- 可以跟随到其他主机的重定向。
- SmartTicker 仍不会读取浏览器 Cookie、提交凭据或提交
	登录表单。

关闭此选项会删除来自未批准来源的当前显示数据，
直到这些主机获批并刷新。

#### 网站隐私选项

如果响应被识别为同时包含肯定和否定选项的隐私/Cookie 表单，
SmartTicker 会暂停并显示页面标题、请求的 URL、
同意 URL、表单摘要以及网站的“接受/拒绝”标签。

- **接受 (Accept)** 会提交该表单提供的隐藏字段，以及您选择的确切“接受”
	控件。
- **拒绝 (Reject)** 会提交这些隐藏字段，以及您选择的确切“拒绝”控件。
- **取消 (Cancel)** 不会提交任何内容。

这是网站的隐私选择，不是 SmartTicker 的逐来源权限批准。

#### 验证所有来源

选择 **验证所有来源 (Validate all sources)** 以查看并测试每个已配置条目。

1. 如果网站访问受限，SmartTicker 会按主机名对未批准条目分组，
	 并为每个主机显示一个来源审查对话框。
2. 查看主机、政策摘要、指导、来源名称和代码。
3. 仅在您已查看网站且获准使用时勾选确认项。
4. 选择 **批准此来源 (Approve this source)**、**跳过此来源 (Skip this source)** 或 **取消验证 (Cancel validation)**。
5. SmartTicker 会测试每个获准条目，并报告通过、失败和跳过的
	 总数。各个问题显示在状态行下方。

批准会在 SmartTicker 内记录权限；它不会授予法律权利，也不会
凌驾于网站条款之上。

## 警报规则

从右键单击菜单打开 **警报 (Alerts)**。规则会在每次成功的
价格刷新后求值，并且只监视正常价格，而非盘前或盘后值。

### 创建规则

1. 选择一个已配置的 **报价 (Quote)**。具有相同代码的条目仍彼此独立。
2. 选择一个 **条件 (Condition)**，并使用固定格式的小数输入数值阈值，例如
	 `250.50`。
3. 可选择 **生效时间 (Active from)**。留空则立即激活。
4. 保持选中 **永不过期 (Never expires)**，或清除它并选择到期日期。
5. 选择 **添加规则 (Add rule)**。

可用比较如下：

| 选项 | 含义 |
| --- | --- |
| `LessThan` | 价格 `<` 阈值。 |
| `LessThanOrEqual` | 价格 `<=` 阈值。 |
| `GreaterThan` | 价格 `>` 阈值。 |
| `GreaterThanOrEqual` | 价格 `>=` 阈值。 |
| `EqualTo` | 价格与阈值完全相等。 |
| `NotEqualTo` | 价格与阈值不同。 |

起始边界包含在内。到期边界也包含在内；超过该边界后，
规则不再触发。SmartTicker 会拒绝早于起始时间的到期时间。

### 规则触发时

已启用且处于计划内的规则，会在其条件从 false 变为 true 时触发一次。
条件持续为 true 时，它不会在每次刷新时都发出通知。价格
离开该条件后，规则会重新待命，并可在价格再次进入条件时触发。

编辑规则，或将其禁用后重新启用，也会使规则重新待命。因此，如果最新
正常价格已经满足条件，已启用规则可能立即触发。
失败或缺失的价格无法触发规则。

一条或多条规则触发时：

- 受影响的价格条目会在已配置的警报闪烁颜色与黑色之间交替显示，持续
	已配置的时间。默认闪烁颜色为洋红色 (`#FF00FF`)。
- 如果启用了 **Buzz**，SmartTicker 会播放已配置的蜂鸣序列。
- 警报消息会标识一条规则，或报告同时触发的规则数量。
- 警报高亮活动期间，行情条会继续滚动。

### 警报输出设置

| 设置 | 范围 | 默认值 |
| --- | --- | --- |
| **Buzz** | 开或关 | 开 |
| Buzz count | 1 至 20 | 15 |
| **闪烁时长 (Blink for)** | 5 至 900 秒，以 15 秒为步长 | 60 秒 |

禁用 Buzz 后，视觉警报仍保持活动。如果多条规则在同一次
求值中触发，SmartTicker 会为该次求值启动一个已配置的蜂鸣序列。
在 **应用设置 > 外观 (App Settings > Appearance)** 下更改 **警报闪烁 (Alert blink)**。它是应用
外观首选项，因此设置导出/导入会包含它，而不是将它放入单独的
警报规则文件。

### 管理已配置的规则

- **编辑 (Edit)** 将规则加载到表单中。选择 **更新规则 (Update rule)** 以保存，或选择 **取消 (Cancel)**
	保持不变。
- **禁用 (Disable)** 会保留规则但停止匹配。**启用 (Enable)** 会使规则重新待命，并
	根据最新正常价格对其求值。
- **删除 (Remove)** 会删除规则。
- 列表显示启用状态、代码、条件摘要和计划。

警报规则更改和警报输出设置会自动保存。

## 本地文件和隐私

SmartTicker 将配置存储在本地，不会将其同步到开发者
服务。

在 Windows 上，默认文件为：

```text
%LocalAppData%\SmartTicker\settings.json
%LocalAppData%\SmartTicker\alerts.json
```

在 Linux 上，.NET 使用当前用户的本地应用数据目录，通常为：

```text
~/.local/share/SmartTicker/settings.json
~/.local/share/SmartTicker/alerts.json
```

### 使用隔离的数据目录

高级诊断和测试运行可以在启动 SmartTicker 前设置 `SMARTTICKER_DATA_DIRECTORY`。
当该值不为空时，两个文件会直接放入解析后的目录，名称为
`settings.json` 和 `alerts.json`；该进程不会使用上面的平台默认值。
建议使用绝对路径，并确保它可写。

PowerShell 示例：

```powershell
$env:SMARTTICKER_DATA_DIRECTORY = 'D:\SmartTicker-Profile'
& 'C:\Program Files\SmartTicker\SmartTicker.Desktop.exe'
```

Linux shell 示例：

```bash
SMARTTICKER_DATA_DIRECTORY="$HOME/.local/share/SmartTicker-Test" smartticker
```

请在进程启动前设置变量。SmartTicker 不会将默认配置文件复制到
所选目录，因此空目录会以空配置启动。指向同一目录的
实例可以看到彼此保存的编辑。请使用正常的“设置”和“警报规则”导出/导入命令进行备份和配置文件转移。

“警报”窗口会显示正在使用的警报文件的确切路径。写入操作先使用临时
文件再替换，以免将部分写入的文件视为当前
配置。

SmartTicker 没有帐户、遥测、分析、广告或云同步。SmartTicker
请求来源时，来源网站会收到正常网络信息，例如您的 IP 地址。打开“帮助”会从 GitHub 请求原始指南。完整
详情请阅读存储库中的 `PRIVACY.md`。

您有责任确保每个来源 URL 和选择器的使用符合
网站条款、许可证、robots 指令和适用法律。

## 故障排除

### 报价显示不可用或没有价格

来源请求会在 20 秒后超时。如果该报价之前有成功的
快照，失败的刷新会让它保持可见；否则报价会显示 **不可用 (Unavailable)**，
直到后续刷新成功。更改选择器前，请阅读验证或刷新错误。

1. 打开 **报价... (Quotes...)**，编辑条目并检查“完整 URL”。
2. 确认已选择 **价格 (Price)**。
3. 如果出现提示，请批准网站。
4. 选择 **验证 URL (Validate URL)** 并阅读确切结果。
5. 运行 **发现价格 (Discover price)**，或检查页面的静态 HTML 并更新选择器。
6. 检查页面是否需要 SmartTicker 无法安全处理的 JavaScript、身份验证或同意操作。
7. 遵守 HTTP 403、429、robots 限制以及网站的自动访问政策。

### 缺少盘前或盘后数据

- 相应市场交易时段可能尚未开始。
- 不存在交易时段值时，页面可能省略该交易时段元素。
- 验证盘前选择器是否指向盘前元素，盘后选择器是否
	指向收盘后元素。
- 重新运行匹配的发现命令，因为网站标记可能已更改。

### 新闻为空

- 确认已选择 **新闻 (News)**。
- 验证来源并运行 **发现新闻 (Discover news)**。
- 确保选择器返回带有可见标题文本的链接。
- 失败或超时的新闻请求会在可用时保留之前成功的标题。
	从未成功返回结果的来源会保持为空，直到后续时间槽成功。
- 标题达到本会话已配置的重复次数限制后会消失。
- 在静态“新闻”中，确认目标报价已在 **显示以下项目的新闻 (Show news for)** 下选中。

### 选择器发现找不到任何内容

发现功能只读取下载的静态 HTML。它无法看到稍后由页面
JavaScript 创建的值。请手动输入经验证的选择器，选择静态页面/数据源，或通过兼容的公开页面使用
经授权且有文档的 API。

### 警报未触发

- 确认所附报价仍然存在、收集价格，并且有成功的正常
	价格。
- 确认规则已启用，并处于其开始/到期计划内。
- 检查比较和阈值。`EqualTo` 要求小数完全相等。
- 请记住，持续为 true 的条件只触发一次；它必须先变为 false 才能
	再次触发，除非您编辑或重新启用该规则。
- 盘前和盘后价格不会驱动警报规则。

### SmartTicker 无法移动或调整大小

- 只能从左侧条中的竖点手柄移动。
- 从边缘或角落调整大小；如果难以选中边缘，请使用可见的右下角标记。
- 行情条内容有意不作为移动区域。

### 静态组或值不符合预期

- 打开 **报价... (Quotes...)**，确认每个条目的“组”值。
- 打开 **报价组... (Quote groups...)** 管理组定义，并查看每个报价当前的
	关联。
- “组”为空的条目显示在 **未分组 (Ungrouped)** 下。
- **涨跌额 (Chg)** 根据最新价和涨跌幅计算；它不是从页面独立提取的。
	百分比不可用时，它会保持为 `—`。
- 使用向上/向下控件重新排序条目，以更改组和行顺序。
- 拖动磁贴标题上的点状手柄以移动整个组。放到另一个磁贴的左
  半边可置于其前，放到右半边可置于其后。
- 当 SmartTicker 未暂停时，选择 **立即刷新价格 (Refresh prices now)** 以更新表格。

### 帮助文本未格式化或导航不移动

- “帮助”窗口应显示格式化的标题、段落、列表、表格、链接和
	代码块，而不是 Markdown 标点。
- 使用左侧的 **本页内容 (On this page)** 跳转到主要部分。“快速
	导航”表格中的链接也会在文档内滚动。
- 关闭并重新打开“帮助”，或更改 **语言 (Language)**，以请求相应的已发布指南。
	在获取在线指南之前，SmartTicker 会显示已安装应用中内置的格式化指南。

### 在线帮助不可用或已过时

- 关闭并重新打开“帮助”，再次请求已发布指南。
- 在浏览器中打开本指南开头附近显示的原始 GitHub 地址，
	直接检查已发布文件。
- 请求失败或返回空文件时，SmartTicker 会使用嵌入的指南。
- 在线更改只有在 `HELPME.md` 或相应的本地化文件
	`help/HELPME.<language-code>.md` 发布到存储库的 `main` 分支后才会出现。
