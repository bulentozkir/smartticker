# SmartTicker 도움말

이 가이드는 SmartTicker 1.0.3에 적용됩니다. 메인 티커, 앱 설정(App Settings),
시세(Quotes), 경고 규칙, 웹사이트 권한, 백업 및 일반적인 문제를 설명합니다.

SmartTicker는 사용자가 구성한 웹페이지에서 공개 정적 HTML을 읽습니다. 시장 데이터
피드를 제공하지 않으며, 추출된 정보가 지연되거나 불완전하거나 잘못될 수 있습니다.
중요한 금융 정보는 신뢰할 수 있는 출처에서 확인하십시오.

## 도움말 및 설정 창 열기

티커를 마우스 오른쪽 단추로 클릭하여 메뉴를 엽니다. 주요 구성 명령은 다음과
같습니다.

- **시세... (Quotes...)**: 시세 또는 뉴스 소스를 추가, 테스트, 편집, 정렬 및 제거합니다.
- **시세 그룹... (Quote groups...)**: 그룹을 만들거나 업데이트 또는 삭제하고 시세를
  그룹에 연결합니다.
- **경고(Alerts)**: 가격 경고 규칙을 만들고 관리합니다.
- **앱 설정... (App Settings...)**: 행, 속도, 새로 고침 간격, 시작, 웹사이트
  액세스, 색, 투명도 및 백업을 구성합니다.
- **보기(View)**: 스크롤 또는 정적 보기와 가격만 또는 가격과 뉴스를 조합한
  상호 배타적인 네 가지 선택 항목 중 하나를 선택합니다.
- **도움말(Help)**: SmartTicker 안에서 이 가이드를 엽니다.
- **SmartTicker 정보(About SmartTicker)**: 설치된 버전과 라이선스 고지를 표시합니다.
- **종료(Exit)**: SmartTicker를 완전히 닫습니다.

도움말 창은 먼저 선택한 앱 언어의 포함된 가이드에 서식을 지정하여 즉시 표시한 다음,
도움말을 열거나 **언어(Language)**를 변경할 때마다 해당 언어의 온라인 가이드를
확인합니다. 한국어 온라인 가이드는 다음과 같습니다.

<https://raw.githubusercontent.com/bulentozkir/smartticker/refs/heads/main/help/HELPME.ko.md>

번역된 가이드는 같은 리포지토리의 `help/HELPME.<language-code>.md`를 사용합니다.
온라인 문서를 다운로드할 수 없으면 SmartTicker는 설치된 애플리케이션에 포함된 해당
번역본을 계속 표시합니다. **언어(Language)**를 변경하면 열려 있는 도움말의 제목,
상태, 탐색 및 전체 가이드가 즉시 업데이트됩니다. 일반적인 제목 표시줄의 닫기
컨트롤로 도움말을 닫으십시오.

## 메인 티커 조작

### 스크롤 또는 정적 시세 보기 선택

SmartTicker는 상호 배타적인 네 가지 표시 모드를 제공합니다. 티커를 마우스 오른쪽
단추로 클릭하고 **보기(View)**를 연 다음 하나를 선택하십시오. 레이아웃이 즉시
변경되고 선택 사항이 저장됩니다.

| 보기 옵션 | 결과 |
| --- | --- |
| **왼쪽에서 오른쪽으로 스크롤: 가격만(Left-to-right scroll: Prices only)** | 메인 티커의 가격 움직이는 글자이며 뉴스는 표시하지 않습니다. 기본값입니다. |
| **왼쪽에서 오른쪽으로 스크롤: 가격과 뉴스(Left-to-right scroll: Prices with News)** | 메인 티커에 가격 및 뉴스 움직이는 글자를 표시합니다. |
| **정적 보기: 가격만(Static view: Prices only)** | 메인 창에 반응형 가격 타일을 표시하며 뉴스 창은 없습니다. |
| **정적 보기: 가격과 뉴스(Static view: Prices with News)** | 반응형 가격 타일과 별도의 정적 **SmartTicker News** 창을 표시합니다. |

이 선택 항목이 추가되기 전에 만든 설정 파일은 저장된 스크롤/정적 및 뉴스 설정에
맞는 조합으로 매핑됩니다. 표시 모드는 티커의 마우스 오른쪽 단추 **보기(View)**
메뉴에서만 관리합니다.

- 두 스크롤 모드 모두에서 가격은 가로 움직이는 글자와 구성된 가격 행 수 및 스크롤
  속도를 사용합니다.
- 두 정적 모드 모두에서 그룹은 왼쪽에서 오른쪽으로 배치된 반응형 타일로 나타납니다.
  창이 너무 좁을 때만 타일이 다음 행으로 줄 바꿈됩니다. 가격은 자동으로 이동하지
  않습니다.
- 각 시세 타일에는 정렬된 **종목 기호(Symbol)**, **최근가(Last)**, **변동(Chg)** 및
  **변동률(Chg%)** 열이 있습니다. 소스 페이지가 별도의 절대 변동 선택기 대신 백분율
  선택기를 제공하므로 **변동(Chg)**은 Last와 Chg%에서 계산됩니다. 두 값 중 하나를
  사용할 수 없으면 `—`를 표시합니다.
- 그룹 머리글을 선택하여 접거나 펼치십시오. 그룹은 구성된 항목 순서에서 해당 시세가
  처음 나타나는 위치를 따르며, 그룹 내 행도 그 순서를 유지합니다.
- 그룹이 없는 항목은 **그룹 없음(Ungrouped)** 아래에 나타납니다.
- Last 위에 마우스를 올려 사용 가능한 장전 및 시간외 값을 확인하십시오. 시세 행을
  두 번 클릭하면 소스 페이지가 열립니다.
- 경고 깜박임과 상승/하락 색은 두 가격 모드에서 모두 작동합니다.
- 뉴스는 정적 **종목 기호 / 헤드라인(Symbol / Headline)** 그룹 타일이 들어 있는 별도의
  **SmartTicker News** 창에서 자동으로 열립니다. 정적 모드에서는 움직이는 글자로
  표시되지 않습니다. 뉴스 창에는 일반 제목 표시줄과 크기 조정 테두리가 있으므로 시세
  창과 뉴스 창을 각각 다른 모니터로 독립적으로 이동할 수 있습니다. 헤드라인 행을 두 번
  클릭하면 소스가 열립니다.
- 처음 시작할 때 뉴스는 간결한 680×340 크기를 사용합니다. 다른 모니터를 사용할 수
  있으면 SmartTicker가 그 모니터에 배치합니다. 모니터가 하나뿐이면 먼저 가격 창의 아래,
  오른쪽, 위 또는 왼쪽에서 빈 영역을 찾습니다. 이후에는 정상적으로 이동하고 크기를
  조정할 수 있습니다.
- 각 뉴스 그룹 안에서 헤드라인은 시세별로 번갈아 배치됩니다. 첫 번째 시세의 헤드라인
  하나, 다음 시세의 헤드라인 하나와 같이 라운드 방식으로 계속됩니다. 따라서 헤드라인이
  많은 한 시세가 그룹 상단 전체를 차지할 수 없습니다.
- 한 줄짜리 **뉴스 표시 대상(Show news for)** 드롭다운을 열고 각 시세를 개별적으로
  선택하거나 선택 취소하십시오. 모두 또는 없음을 포함하여 원하는 시세 조합을 표시할 수
  있습니다. 단추는 현재 선택을 요약하고 항목에는 시세와 소스가 포함되므로 중복된 종목
  기호도 서로 독립적으로 유지됩니다. 선택 취소한 시세는 설정 파일에
  `hiddenNewsQuotes`로 저장되므로 다시 시작한 뒤에도 유지되고 설정 백업에도 포함됩니다.
- 시세 또는 뉴스 타일 머리글 옆의 점선 핸들을 끌어 다른 타일의 왼쪽 또는 오른쪽 절반에
  놓으십시오. 두 창 모두에서 순서가 변경되며 기본 구성 항목을 재정렬하여 저장됩니다.
- 행이 많은 그룹은 자체 경계 타일 안에서 스크롤됩니다. 줄 바꿈된 타일 행이 현재 창 높이에
  맞지 않을 때만 전체 보기가 세로로 스크롤됩니다.

**SmartTicker News**를 닫아도 뉴스 수집은 비활성화되지 않습니다. 다시 열려면 가격 창을
마우스 오른쪽 단추로 클릭하고 **보기 > 정적 뉴스 창 열기(View > Open static news window)**를
선택하십시오. **정적 보기: 가격만(Static view: Prices only)**을 선택하면 닫히고,
**정적 보기: 가격과 뉴스(Static view: Prices with News)**를 선택하면 다시 열립니다. 어느
스크롤 옵션을 선택해도 별도의 뉴스 창이 닫히며, 가격과 뉴스 스크롤 옵션은 메인 티커의
뉴스 움직이는 글자를 복원합니다.

모드를 전환하면 해당 보기에 저장된 크기가 적용됩니다. 스크롤 티커, 정적 가격 창 및 정적
뉴스 창은 각각 독립적인 너비와 높이를 유지합니다.

### 티커 이동

왼쪽의 좁은 스트립 위쪽에 있는 세로 점 그립을 누른 채 티커를 끌고 마우스 단추를
놓으십시오. 티커 텍스트는 끌기 영역이 아니므로 콘텐츠를 선택하거나 클릭해도 실수로 창
이동이 시작되지 않습니다.

### 티커 크기 조정

크기 조정 커서가 나타날 때까지 포인터를 가장자리 또는 모서리로 이동한 다음 누른 채
끄십시오. 오른쪽 아래 모서리에는 작은 크기 조정 표시가 있습니다. 최소 창 너비는 420
픽셀입니다. 스크롤 높이는 50~900픽셀, 정적 가격 높이는 420~4320픽셀, 정적 뉴스 높이는
240~4320픽셀입니다.

수동으로 크기를 조정하면 끌기가 끝난 뒤 활성 보기에 저장된 크기가 업데이트됩니다. 세
크기 쌍은 모두 설정 백업에 포함됩니다. 창 위치는 저장되지 않습니다. 선택한 가격/뉴스
행과 스크롤 글꼴 크기에 비해 스크롤 크기가 너무 작으면 SmartTicker가 저장된 높이를
자동으로 늘립니다. 따라서 **왼쪽에서 오른쪽으로 스크롤: 가격과 뉴스(Left-to-right scroll:
Prices with News)**를 선택하면 뉴스 행을 조용히 숨기지 않고 항상 필요한 공간을 확보합니다.
창을 열거나 이동할 때마다 SmartTicker는 왼쪽 위 32픽셀 모서리 중 적어도 하나를 화면의
작업 영역 안에 유지하고 전역 X 및 Y를 최소 1로 제한합니다. 따라서 모니터 연결이 끊어진
후에도 이동 그립이나 제목 모서리에 마우스로 접근할 수 있습니다.

### 일시 중지 및 재개

이동 그립 아래의 상태 단추를 선택하거나 마우스 오른쪽 단추로 클릭하고 **일시 중지 / 재개
(Pause / Resume)**를 선택하십시오. 일시 중지하면 자동 가격 및 뉴스 새로 고침이 중지되고
움직이는 글자가 멈춥니다. 또한 두 수동 새로 고침 명령이 새 작업을 시작하지 못하게 합니다.
이미 진행 중이던 소스 요청은 일시 중지만을 이유로 강제로 취소되지 않으며 활동이 완전히
멈추기 전에 완료될 수 있습니다. 재개하면 자동 타이머가 다시 시작됩니다.

Windows에서 SmartTicker는 UI를 시작하기 전에 OS 프로세스 우선 순위를 자동으로
**낮음(Low)**으로 설정하고 Windows **효율성 모드(Efficiency mode)**(EcoQoS)를 사용하도록
설정합니다. 이 동작을 위한 앱 설정은 없습니다. 또한 오버헤드가 낮은 소프트웨어 렌더링
경로를 사용합니다. 움직이는 글자 타이밍은 구성된 속도에 맞게 조정되고, 일시 중지되었거나
비어 있거나 분리된 움직이는 글자는 애니메이션 타이머를 중지합니다. 변경되지 않은 행은
중복된 시각적 알림을 억제합니다. 경고 깜박임과 3초 동안의 갈색 변경 강조 표시는 의도된
동작이며 스크롤을 일시 중지하지 않습니다. Linux 프로세스 예약은 운영 체제에 맡깁니다.
Windows가 프로세스 설정 중 하나를 거부하면 SmartTicker는 진단 추적에 실패를 보고하고
계속 시작합니다.

### 링크 열기

뉴스 헤드라인을 포함하여 링크된 티커 텍스트를 두 번 클릭하면 기본 브라우저에서 소스가
열립니다. SmartTicker는 한 번 클릭으로 링크를 열지 않습니다.

### 변경 강조 표시

새로 고칠 때마다 SmartTicker는 변경된 항목을 3초 동안 갈색 배경으로 잠시 표시합니다.

- 가격이 이전 동기화와 다른 시세.
- 해당 시세의 이전 동기화에는 없었던 각 헤드라인.

시작 후 첫 번째 동기화에는 비교할 이전 값이 없으므로 아무것도 강조 표시하지 않습니다.
발생한 경고는 자체 경고 깜박임 색을 유지하며 우선 적용됩니다.

### 메인 메뉴 참조

| 명령 | 효과 |
| --- | --- |
| **지금 가격 새로 고침(Refresh prices now)** | 시차를 둔 가격 주기를 다시 시작하고 SmartTicker가 일시 중지되지 않았을 때 첫 번째 시간 슬롯을 요청합니다. |
| **지금 뉴스 새로 고침(Refresh news now)** | 시차를 둔 뉴스 주기를 다시 시작하고 SmartTicker가 일시 중지되지 않았을 때 첫 번째 시간 슬롯을 요청합니다. |
| **일시 중지 / 재개(Pause / Resume)** | 새로 고침과 움직이는 글자 이동을 전환합니다. |
| **보기 > 왼쪽에서 오른쪽으로 스크롤: 가격만(View > Left-to-right scroll: Prices only)** | 가로 가격 움직이는 글자만 사용합니다. 기본값입니다. |
| **보기 > 왼쪽에서 오른쪽으로 스크롤: 가격과 뉴스(View > Left-to-right scroll: Prices with News)** | 두 가로 움직이는 글자를 모두 사용합니다. |
| **보기 > 정적 보기: 가격만(View > Static view: Prices only)** | 반응형 정적 시세 타일만 사용합니다. |
| **보기 > 정적 보기: 가격과 뉴스(View > Static view: Prices with News)** | 시세 타일과 별도의 정적 뉴스 창을 사용합니다. |
| **보기 > 정적 뉴스 창 열기(View > Open static news window)** | 닫힌 별도 뉴스 창을 다시 엽니다. 뉴스가 활성화된 정적 모드에서 사용할 수 있습니다. |
| **언어(Language)** | 메뉴, 상태 텍스트 및 전체 도움말 가이드에 사용할 16개 언어 중 하나를 선택합니다. 열려 있는 도움말 창은 즉시 업데이트됩니다. |

행 표시 여부, 언어 및 기타 구성 값은 자동으로 저장됩니다.

## 시세

마우스 오른쪽 단추 메뉴에서 **시세... (Quotes...)**를 여십시오. 구성된 각 항목은 종목
기호 하나와 웹페이지 하나를 나타냅니다. 중복된 종목 기호가 허용되며, 각 항목에 자체
소스, 선택기, 수집 옵션 및 경고가 있으므로 서로 독립적으로 유지됩니다.

### 게시된 샘플로 빠르게 시작

항목이 없으면 시세 창에 **GitHub에서 샘플 시세 가져오기(Import sample quotes from
GitHub)**가 표시됩니다. 이 기능은 리포지토리 샘플을 다운로드하고 현재 애플리케이션
설정을 바꿉니다. 사용하기 전에 가져온 모든 URL과 각 웹사이트의 현재 약관을 검토하십시오.
나중에 모든 샘플 항목을 편집하거나 제거할 수 있습니다.

시세 및 앱 설정 창 위쪽의 **샘플 시세 구성 가져오기(Import Sample Quotes Config)**도
확인 절차를 거쳐 언제든지 같은 작업을 수행합니다.

- SmartTicker는 **계속하시겠습니까? (Are you sure?)**라고 묻고 다운로드가 기존 시세,
  시세 그룹, 소스 승인, 보기, 모양 및 기타 앱 설정을 바꾼다고 경고합니다. 경고 규칙은
  자체 파일에 있으며 삭제되지 않습니다.
- **기존 구성 내보내기... (Export existing config...)**는 선택 사항입니다. 현재 구성을
  로컬 JSON 파일에 저장한 다음 같은 확인 화면으로 돌아갑니다.
- **샘플 시세 구성 가져오기(Import Sample Quotes Config)**는 인터넷에서 샘플을 다운로드하고
  구성을 바꿉니다.
- **취소(Cancel)**는 아무것도 변경하지 않습니다.

### 시세 또는 뉴스 항목 추가

1. `MSFT`와 같은 **티커(Ticker)** 레이블을 입력하십시오. SmartTicker는 앞뒤 공백을
   제거하고 대문자로 저장합니다.
2. 필요하면 조회에서 기존 **그룹(Group)**을 선택하거나 `Nasdaq`, `Precious Metals`,
   `Mag 7` 같은 새 이름을 입력하십시오. **그룹 없음(Ungrouped)**으로 두려면 비워 두십시오.
3. **소스(Source)** 사전 설정을 선택하십시오.
4. **URL 접미사(URL suffix)**를 입력하거나 **사용자 지정 URL(Custom URL)**을 사용할 때는
   전체 URL을 입력하십시오.
5. **수집(Collect)**에서 **가격(Price)**, **뉴스(News)** 또는 둘 다를 선택하십시오. 하나
   이상을 선택해야 합니다.
6. 선택기를 직접 입력하거나 검색 단추를 사용하십시오. 선택적 선택기를 비워 두면 기본 제공
   검색을 사용합니다.
7. **URL 유효성 검사(Validate URL)**를 선택하여 정규 가격 및/또는 헤드라인을 테스트하십시오.
8. SmartTicker가 소스 승인을 요청하면 웹사이트를 검토하고 해당 사이트에서 수집할 권한이
   있을 때만 확인하십시오.
9. **독립 항목 추가(Add independent entry)**를 선택하십시오. SmartTicker가 항목을 저장하고
   활성화된 데이터를 즉시 새로 고칩니다.

### 시세 그룹화

그룹은 사용자가 정의하는 이름 있는 모음입니다. 거래소나 기본 제공 범주에 연결되지 않으므로
시장, 자산 유형, 전략, 포트폴리오, 지역 또는 다른 방식으로 항목을 구성할 수 있습니다. 이름은
앞뒤 공백이 제거되고 Unicode를 사용할 수 있으며 최대 80자입니다. 각 시세는 최대 한 그룹에
속할 수 있습니다.

그룹 필드 옆의 **그룹 관리(Manage groups)**를 사용하거나 티커의 마우스 오른쪽 단추 메뉴에서
**시세 그룹... (Quote groups...)**을 선택하십시오. 이 창에는 세 작업 영역이 있습니다.

- 왼쪽에서 **그룹 이름(Group name)**을 입력한 다음 **만들기(Create)**를 선택하십시오. 기존
  그룹을 선택하고 이름을 편집한 뒤 **업데이트(Update)**를 선택하거나 **삭제(Delete)**를
  선택하십시오. 빈 그룹도 유지됩니다.
- 오른쪽에서 시세를 선택하십시오. 현재 그룹은 **현재 그룹(Current group)** 열에 표시되며,
  **그룹 없음(Ungrouped)**은 연결이 없음을 의미합니다.
- 가운데에서 그룹 하나와 시세 하나를 선택한 후 **연결(Associate)**을 선택하십시오. 해당
  시세가 이미 다른 그룹에 속해 있으면 SmartTicker가 선택한 그룹으로 이동합니다.
- **연결 제거(Remove association)**를 선택하면 선택한 시세만 **그룹 없음(Ungrouped)**으로
  돌아갑니다.
- 그룹을 삭제하면 모든 시세가 **그룹 없음(Ungrouped)**으로 돌아갑니다. 시세, 소스, 현재
  데이터 및 경고는 삭제되지 않습니다.
- 시세를 추가하거나 편집할 때 조회에서 기존 그룹을 선택하거나 새 그룹 이름을 입력할 수도
  있습니다.
- 구성된 항목(Configured entries)의 위/아래 컨트롤을 사용하여 정적 표의 그룹 및 행 순서를
  지정하십시오.
- 정적 모드에서는 타일 머리글을 끌어 전체 그룹의 순서를 직접 바꿀 수 있습니다. 별도의 시세
  및 뉴스 창에서 같은 순서가 사용됩니다.

게시된 샘플에는 여섯 개의 예제 그룹이 들어 있지만 정적 모드는 기본적으로 꺼져 있습니다.
가져온 후 정적 보기를 활성화하면 해당 그룹을 표로 볼 수 있습니다.

### 소스 사전 설정 및 URL

| 소스 | 입력할 내용 | SmartTicker가 표시하는 정책 |
| --- | --- | --- |
| **Yahoo Finance** | `https://finance.yahoo.com/` 뒤의 접미사(예: `quote/MSFT/`). | 서면 허가가 필요합니다. Yahoo 약관은 사전 허가 없는 자동 수집을 금지합니다. |
| **CNBC** | `https://www.cnbc.com/` 뒤의 접미사. | 사이트의 현재 정책과 robots 지시문을 확인하십시오. |
| **Trading Economics** | `https://tradingeconomics.com/` 뒤의 접미사. | 문서화된 API 또는 승인된 피드를 우선 사용하고 사이트의 현재 정책을 확인하십시오. |
| **사용자 지정 URL(Custom URL)** | 공개 `http://` 또는 `https://` 페이지의 전체 URL. | 사이트의 약관, 개인 정보 보호 정책 및 자동 액세스 규칙을 검토하십시오. |

절대 HTTP 및 HTTPS URL만 허용됩니다. 사용자 이름이나 암호가 포함된 URL은 거부됩니다.
브라우저 로그인은 SmartTicker에 페이지 수집 권한을 부여하지 않으며 SmartTicker는 인증된
브라우저 세션을 사용하지 않습니다.

**전체 URL(Full URL)** 행은 사전 설정 접두사와 입력한 접미사로 만든 최종 주소를 표시합니다.
유효성 검사나 검색 전에 확인하십시오.

### 수집 옵션

- **가격(Price)**은 정규 가격을 요청합니다. 선택적인 변동, 장전 및 시간외 선택기는 같은
  다운로드 페이지에서 평가됩니다.
- **뉴스(News)**는 페이지에서 헤드라인 링크를 요청합니다.
- 둘 다 선택하면 항목 하나가 티커의 두 영역 모두에 데이터를 제공할 수 있습니다.
- 둘 다 선택 취소하면 유효하지 않습니다.

### 선택기 필드 참조

CSS 선택기는 웹페이지의 정적 HTML 안에 있는 요소를 식별합니다. 자동 검색이 필요한 값을
찾지 못하는 경우가 아니면 선택기를 생략할 수 있습니다.

| 필드 | SmartTicker가 추출하는 값 |
| --- | --- |
| **가격 선택기(Price selector)** | 정규 가격 또는 종가. |
| **가격 변동(Price change)** | 정규 세션의 백분율 변동. 비어 있으면 기본 제공 변동 검색을 시도합니다. |
| **장전 선택기(Pre-market selector)** | 페이지에 해당 세션이 있을 때의 장전 가격. |
| **장전 변동(Pre-market change)** | 장전 백분율 변동. |
| **시간외 선택기(After-hours selector)** | 장후 또는 시간외 가격. |
| **시간외 변동(After-hours change)** | 장후 또는 시간외 백분율 변동. |
| **뉴스 선택기(News selector)** | 헤드라인 링크. 앵커 또는 결과에 링크가 포함되는 컨테이너를 선택하십시오. |

장전 및 시간외 값은 정규 가격을 보완하며 대체하지 않습니다. 해당 시장 세션이 아닐 때는
페이지에서 이러한 요소를 생략할 수 있습니다.

게시된 샘플에서 사용하는 Yahoo Finance 선택기의 예는 다음과 같습니다.

```text
Price:                  [data-testid="qsp-price"]
Price change:           section.primary span[data-testid="qsp-price-change-percent"]
Pre-market price:       section.secondary span[data-testid="qsp-pre-price"]
Pre-market change:      section.secondary span[data-testid="qsp-pre-price-change-percent"]
After-hours price:      section.secondary span[data-testid="qsp-post-price"]
After-hours change:     section.secondary span[data-testid="qsp-post-price-change-percent"]
```

웹사이트 마크업은 시간이 지나면 바뀝니다. 예제는 시작점으로 취급하고 영구적인 계약으로
간주하지 마십시오.

### 선택기 검색

각 선택기 필드에는 해당하는 **검색(Discover)** 단추가 있습니다.

1. 소스 URL을 완성하고 승인이 필요한 경우 웹사이트를 승인하십시오.
2. 정확한 값 유형에 맞는 검색 단추를 선택하십시오.
3. SmartTicker가 공개 정적 HTML을 다운로드하고 가능한 선택기를 샘플 값, 신뢰도 백분율 및
   이유와 함께 도구 설명에 표시합니다.
4. 제안 옆의 **사용(Use)**을 선택하여 해당 필드에 복사하십시오.
5. 사용하기 전에 결과를 검사하거나 관찰하십시오.

검색은 JavaScript를 실행하거나 로그인하거나 액세스 제어를 우회하거나 브라우저를 검사하지
않습니다. JavaScript로만 생성되는 값에는 검색 가능한 선택기가 없을 수 있습니다. 검색 유형을
분리하여 장전 값과 시간외 값이 섞이지 않도록 의도적으로 방지합니다.

### 소스 유효성 검사

**URL 유효성 검사(Validate URL)**는 페이지를 요청하고 읽을 수 있는 정규 가격 및/또는
헤드라인 수를 보고합니다. SmartTicker가 테스트용 임시 레이블을 사용하므로 티커를 입력하기
전에도 안전하게 사용할 수 있습니다.

현재 이 유효성 검사에서는 장전 및 시간외 선택기 필드 네 개를 검사하지 않습니다. 검색의 샘플
값을 사용한 다음 표시된 세션 데이터를 확인하십시오.

일반적인 실패에는 HTTP 오류, 시간 초과, 누락된 값, 헤드라인 0개, 승인되지 않은 소스 권한,
JavaScript 전용 콘텐츠 또는 오래된 선택기가 있습니다.

### 뉴스 반복 제한

**최대 _N_회 표시(Show max _N_ times)**에는 1~100을 입력할 수 있으며 기본값은 5입니다.
SmartTicker는 같은 헤드라인 제목이 반환된 완료된 뉴스 새로 고침 주기마다 한 번 표시된 것으로
계산합니다. 제목이 구성된 횟수만큼의 주기에 나타나면 현재 애플리케이션 세션의 나머지 기간에는
제외됩니다. 해당 항목을 편집하거나 제거하면 반복 기록이 지워집니다.

### 항목 편집, 순서 변경 및 제거

**구성된 항목(Configured entries)** 목록은 종목 기호, 그룹, 소스, URL, 수집 배지, 정규 가격
선택기, 뉴스 선택기 및 뉴스 반복 제한을 표시합니다.

- **편집(Edit)**은 항목을 양식에 불러옵니다. 적용하려면 **변경 내용 저장(Save changes)**을,
  양식 변경 내용을 버리려면 **편집 취소(Cancel edit)**를 선택하십시오.
- 위쪽 및 아래쪽 화살표 단추는 티커 순서를 변경하고 즉시 저장합니다.
- **제거(Remove)**는 항목과 현재 표시된 데이터를 삭제합니다.
- 경고 규칙이 해당 항목을 대상으로 하면 SmartTicker가 그 규칙을 삭제할지 묻습니다. 일치하는
  구성 시세가 없는 경고는 발생할 수 없습니다.
- 항목 이름을 바꾸면 해당 항목에 연결된 경고 규칙의 표시 종목 기호가 업데이트됩니다.

## 앱 설정

마우스 오른쪽 단추 메뉴에서 **앱 설정... (App Settings...)**을 여십시오. 변경 내용은 즉시
적용되고 자동으로 저장되며 적용(Apply) 단추는 없습니다.

### 티커 행 및 속도

| 설정 | 선택 항목 | 기본값 | 효과 |
| --- | --- | --- | --- |
| 가격 행(Price rows) | 1~8 | 1 | 병렬 가격 움직이는 글자 행 수. |
| 가격 스크롤 속도(Price scroll speed) | 20, 30, 40, 50, 65, 80, 100 또는 120 px/sec | 50 | 가격 움직이는 글자 속도. |
| 뉴스 행(News rows) | 1~8 | 1 | 병렬 헤드라인 움직이는 글자 행 수. |
| 뉴스 스크롤 속도(News scroll speed) | 20, 30, 40, 50, 65, 80, 100 또는 120 px/sec | 40 | 뉴스 움직이는 글자 속도. |
| 스크롤 글꼴 크기(Scrolling font size) | 9~24 pt | 14 pt | 스크롤 행의 가격 및 뉴스 텍스트. |
| 정적 글꼴 크기(Static font size) | 9~24 pt | 13 pt | 정적 행의 시세 및 헤드라인 텍스트. |
| 가격 새로 고침(Price refresh) | 30~300초, 15초 단위 | 60초 | 허용된 모든 가격 항목이 한 번의 예약 새로 고침을 받는 시간. |
| 뉴스 새로 고침(News refresh) | 30~300초, 15초 단위 | 300초 | 허용된 모든 뉴스 항목이 한 번의 예약 새로 고침을 받는 시간. |

정적 그룹 표가 활성 상태이면 가격 행과 가격 스크롤 속도를 사용할 수 없습니다. 이 모드는
모든 가격 항목을 표시하고 어느 창도 자동 스크롤하지 않기 때문입니다. 뉴스 행 및 속도 설정은
스크롤 보기에 사용하도록 유지됩니다.

가격 및 뉴스 요청은 함께 시작하는 대신 전체 간격에 걸쳐 1초 시간 슬롯으로 독립적으로
분산됩니다. 예를 들어 30초 동안 60개 항목이면 초당 2개 항목이 예약되고, 30초 동안 5개
항목이면 약 6초마다 하나가 예약됩니다. 한 번에 최대 네 개의 소스 요청이 실행되고, 같은
항목과 스트림에 대한 중복 작업은 건너뛰며, 놓친 슬롯은 한꺼번에 다시 실행되지 않습니다.
**지금 가격 새로 고침(Refresh prices now)** 또는 **지금 뉴스 새로 고침(Refresh news now)**은
해당 스트림만 다시 시작하고 첫 번째 슬롯을 요청합니다. 대체 데이터를 읽는 동안에도 이전에
성공한 가격과 헤드라인은 계속 표시됩니다.

각 HTTP 요청에는 고정된 20초 제한 시간이 있습니다. 느린 소스가 UI 디스패처를 붙잡거나 이후
슬롯에서 남은 요청 용량을 사용하지 못하게 하지 않습니다. SmartTicker는 HTTP 403 및 429 같은
실패를 보고하고 제한을 우회하지 않습니다. robots 지시문, crawl-delay 값 또는 서버 백오프
명령을 자동으로 구문 분석하거나 적용하지 않으므로 규정을 준수하는 소스를 선택하고 불필요하게
잦은 요청을 피하십시오.

### 창 크기

앱 설정은 독립적인 세 크기 쌍을 저장합니다.

| 창 | 너비 | 높이 | 기본값 |
| --- | --- | --- | --- |
| 스크롤 보기 | 420–7680 px | 50–900 px | 980 × 64 px |
| 정적 가격 보기 | 420–7680 px | 420–4320 px | 980 × 420 px |
| 정적 뉴스 보기 | 420–7680 px | 240–4320 px | 680 × 340 px |

해당 창이나 보기가 활성 상태일 때 값을 변경하면 즉시 적용됩니다. 게시된 샘플은 스크롤 보기에
1200 × 96, 정적 가격에 1200 × 720, 정적 뉴스에 760 × 480을 사용하며 스크롤 텍스트는
15포인트, 정적 텍스트는 14포인트입니다. 활성화된 행에 필요한 공간보다 작은 스크롤 높이는
필요한 최솟값까지 자동으로 증가합니다.

**보기(View)** 아래의 네 선택 항목을 사용하여 뉴스 표시 여부와 레이아웃의 스크롤 또는 정적
상태를 선택하십시오. 보기를 변경해도 구성된 항목은 삭제되지 않습니다.

### 로그인할 때 SmartTicker 시작

**로그인할 때 SmartTicker 시작(Start SmartTicker when I sign in)**을 사용하면 설치된 실행 파일을
현재 사용자에게만 등록합니다.

- Windows에서 SmartTicker는 현재 사용자의 `Run` 레지스트리 키를 사용합니다.
- freedesktop 자동 시작 규칙을 지원하는 Linux 데스크톱에서 SmartTicker는 사용자의 자동 시작
  디렉터리에 `smartticker.desktop`을 기록합니다.
- SmartTicker에 지원되는 등록 메커니즘이 없는 플랫폼에서는 이 옵션을 사용할 수 없습니다.

운영 체제가 기준입니다. SmartTicker 외부에서 시작 설정이 변경되면 다음에 설정을 불러올 때
확인란에 OS 상태가 반영됩니다.

### 웹사이트 액세스

**웹사이트 쿠키 및 호스트 간 리디렉션 허용(Allow website cookies and cross-host redirects)**은
기본적으로 비활성화되어 있습니다.

비활성화된 경우:

- SmartTicker는 각 웹사이트 호스트를 요청하기 전에 한 번의 명시적 승인을 요구합니다.
- 웹사이트 쿠키를 허용하지 않습니다.
- 다른 호스트로의 리디렉션을 차단합니다.
- 승인된 호스트를 로컬 설정에 기억합니다.

활성화된 경우:

- SmartTicker가 호스트별 승인 단계를 건너뜁니다.
- 요청한 웹사이트가 설정한 쿠키는 격리된 메모리 내 컨테이너에만 보관되며 SmartTicker가
  종료되면 사라집니다.
- 다른 호스트로의 리디렉션을 따를 수 있습니다.
- SmartTicker는 여전히 브라우저 쿠키를 읽거나 자격 증명 또는 로그인 양식을 제출하지 않습니다.

이 옵션을 끄면 승인되지 않은 소스에서 현재 표시된 데이터가 제거되며, 해당 호스트가 승인되고
새로 고쳐질 때까지 표시되지 않습니다.

#### 웹사이트 개인 정보 선택

긍정 및 부정 선택 항목이 모두 있는 개인 정보/쿠키 양식으로 응답이 인식되면 SmartTicker가
일시 중지되고 페이지 제목, 요청된 URL, 동의 URL, 양식 요약 및 웹사이트의 수락/거부
(Accept/Reject) 레이블을 표시합니다.

- **수락(Accept)**은 양식에서 제공한 숨겨진 필드와 선택한 정확한 수락 컨트롤을 제출합니다.
- **거부(Reject)**는 해당 숨겨진 필드와 선택한 정확한 거부 컨트롤을 제출합니다.
- **취소(Cancel)**는 아무것도 제출하지 않습니다.

이는 웹사이트의 개인 정보 선택이며 SmartTicker의 소스별 권한 승인이 아닙니다.

#### 모든 소스 유효성 검사

구성된 모든 항목을 검토하고 테스트하려면 **모든 소스 유효성 검사(Validate all sources)**를
선택하십시오.

1. 웹사이트 액세스가 제한된 경우 SmartTicker가 승인되지 않은 항목을 호스트 이름별로
   그룹화하고 호스트마다 하나의 소스 검토 대화 상자를 표시합니다.
2. 호스트, 정책 요약, 지침, 소스 이름 및 종목 기호를 검토하십시오.
3. 웹사이트를 검토하고 사용할 권한이 있을 때만 확인란을 선택하십시오.
4. **이 소스 승인(Approve this source)**, **이 소스 건너뛰기(Skip this source)** 또는
   **유효성 검사 취소(Cancel validation)**를 선택하십시오.
5. SmartTicker가 허용된 각 항목을 테스트하고 통과, 실패 및 건너뛴 합계를 보고합니다. 개별
   문제는 상태 줄 아래에 나타납니다.

승인 기록은 SmartTicker 내부에 권한을 기록할 뿐, 법적 권리를 부여하거나 웹사이트 약관을
무시하도록 허용하지 않습니다.

### 모양

**창 투명도(Window transparency)**는 티커 배경만 변경합니다. 텍스트는 불투명하게 유지됩니다.
범위는 20%~100%이며 5% 단위이고 기본값은 100%입니다.

색 필드에는 `#RRGGBB` 16진수 값을 사용할 수 있으며 색 선택기도 제공됩니다.

| 색 | 기본값 | 용도 |
| --- | --- | --- |
| 배경(Background) | `#10151D` | 투명도를 적용하기 전 티커 배경. |
| 시세 이름(Quote name) | `#79C0FF` | 종목 기호/소스 레이블. |
| 종가(Close price) | `#FFA657` | 정규 가격. |
| 시간외(After hours) | `#00E5FF` | 장전 및 시간외 가격. |
| 뉴스 1번째(News 1st) | `#FFFFFF` | 1, 5, 9번째 등의 헤드라인. |
| 뉴스 2번째(News 2nd) | `#00E5FF` | 2, 6, 10번째 등의 헤드라인. |
| 뉴스 3번째(News 3rd) | `#A3E635` | 3, 7, 11번째 등의 헤드라인. |
| 뉴스 4번째(News 4th) | `#79C0FF` | 4, 8, 12번째 등의 헤드라인. |
| 상승 변동(Change up) | `#3FB950` | 양의 백분율 변동. |
| 하락 변동(Change down) | `#F85149` | 음의 백분율 변동. |
| 경고 깜박임(Alert blink) | `#FF00FF` | 발생한 가격 경고이며 검은색과 번갈아 표시. |

**기본값으로 재설정(Reset to defaults)**은 위의 모든 색과 100% 배경 불투명도를 복원합니다.
행, 속도, 글꼴 크기, 창 크기, 소스, 새로 고침 간격, 경고 또는 언어는 재설정하지 않습니다.

### 백업 및 복원

SmartTicker는 애플리케이션 설정과 경고 규칙을 별도의 JSON 파일에 보관하며 백업 유형마다
별도의 단추를 제공합니다.

#### 설정 내보내기 및 가져오기

- **설정 내보내기... (Export settings...)**는 구성된 항목, 그룹 할당, 그룹 정의, 숨겨진 뉴스
  시세, 항목 순서, 선택기, 스크롤/정적 시세 보기 선택, 승인된 호스트, 행 표시 여부, 행,
  속도, 스크롤/정적 글꼴 크기, 세 창 크기 쌍, 새로 고침 간격, 시작 기본 설정, 웹사이트
  액세스 옵션, 경고 깜박임 색을 포함한 색, 투명도 및 언어를 기록합니다.
- **설정 가져오기... (Import settings...)**는 변경하기 전에 전체 파일의 유효성을 검사합니다.
  거부된 파일은 현재 설정을 변경하지 않습니다.
- 가져오기에 성공하면 구성된 모든 항목과 애플리케이션 기본 설정이 바뀝니다. 별도의 경고 규칙
  파일은 바뀌지 않습니다.
- 그룹은 그룹 정의 자체와 함께 설정 파일에 시세 할당으로 포함되므로 시세가 없는 그룹도
  백업에 유지됩니다. 그룹 전용 내보내기 또는 가져오기 파일은 없습니다.
- 시작 기본 설정은 설정 백업에 있지만 가져오더라도 OS 시작 등록을 자동으로 변경하지 않습니다.
  운영 체제가 기준입니다. 현재 컴퓨터에서 등록을 변경하려면 시작(Startup) 확인란을 사용하십시오.
- 가져오기 파일은 1 MiB, 스키마 버전 1 및 최대 200개 구독으로 제한됩니다. 알 수 없는 속성,
  중복 ID, 잘못된 URL, 잘못된 색, 잘못된 범위 또는 지원되지 않는 언어 코드는 무시되지 않고
  거부됩니다.

#### 경고 규칙 내보내기 및 가져오기- **경고 규칙 내보내기... (Export alert rules...)**는 모든 규칙과 Buzz, 버즈 횟수 및 깜박임 기간을 기록합니다.
- **경고 규칙 가져오기... (Import alert rules...)**는 전체 파일의 유효성을 검사한 다음 현재의
  모든 규칙과 경고 발생 설정을 바꿉니다.
- 규칙은 먼저 구독 ID로 다시 연결됩니다. ID가 다르면 SmartTicker가 대/소문자를 구분하지 않고
  종목 기호 일치를 시도합니다.
- 일치하는 시세가 없는 가져온 규칙도 유지되지만 발생할 수 없습니다. 가져오기 상태는 다시 연결된
  규칙 수와 일치하지 않은 규칙 수를 보고합니다.
- 경고 가져오기 파일은 1 MiB로 제한됩니다.

다른 컴퓨터로 전송하려면 애플리케이션 설정을 먼저 가져오고 경고 규칙을 두 번째로 가져오십시오.
경고를 두 번째로 가져오면 규칙이 종목 기호를 통해 새 구독 ID에 다시 연결될 수 있습니다.

### 구성 파일을 직접 편집

앱 설정의 **현재 앱 구성 편집(Edit Current App Config)** 및 **현재 경고 규칙 편집(Edit Current
Alert Rules)**은 시스템에서 `.json`에 연결된 텍스트 편집기로 실제 JSON 파일을 엽니다. 이
기능은 고급 사용자용이며 SmartTicker의 창에서 같은 설정을 위험 없이 관리할 수 있습니다.

두 단추 모두 먼저 현재 파일을 내보내도록 요청하는 확인 메시지를 표시합니다. 반드시 내보내십시오.
직접 편집하면 파일이 손상될 수 있고 실행 취소 기능이 없습니다.

- **기존 구성 내보내기... (Export existing config...)**는 현재 파일을 저장한 다음 같은 확인
  메시지로 돌아갑니다.
- **텍스트 편집기에서 열기(Open in text editor)**는 실제 파일을 엽니다.
- **취소(Cancel)**는 아무것도 변경하지 않습니다.

SmartTicker는 파일을 감시하고 편집기가 저장하는 즉시 다시 불러옵니다.

- 유효한 파일은 즉시 적용되고 티커가 다시 시작 없이 업데이트됩니다.
- 잘못된 JSON, 스키마 위반 또는 다른 유효성 검사 오류는 거부됩니다. 실행 중인 구성은 그대로
  유지되고 앱 설정 창에 문제가 보고됩니다.
- 편집이 거부된 후 파일을 수정하거나 **설정 가져오기... (Import settings...)** 또는
  **경고 규칙 가져오기... (Import alert rules...)**를 사용하여 유효한 내보내기를 복원하십시오.
- 다른 프로그램에서 계속 잠근 파일은 잠시 다시 시도한 후 보고됩니다.

두 파일은 서로 분리되어 있으므로 경고 규칙 파일 편집에도 같은 규칙이 적용되며 애플리케이션
설정에는 영향을 주지 않습니다.

## 경고 규칙

마우스 오른쪽 단추 메뉴에서 **경고(Alerts)**를 여십시오. 규칙은 가격을 성공적으로 새로 고칠
때마다 평가되며 장전 또는 시간외 값이 아닌 정규 가격만 감시합니다.

### 규칙 만들기

1. 구성된 **시세(Quote)**를 선택하십시오. 종목 기호가 같은 항목도 서로 구분됩니다.
2. **조건(Condition)**을 선택하고 `250.50`과 같은 고정 소수점 형식으로 숫자 임계값을
   입력하십시오.
3. 필요하면 **활성 시작(Active from)**을 선택하십시오. 즉시 활성화하려면 비워 두십시오.
4. **만료 안 함(Never expires)**을 선택한 상태로 두거나 선택 취소하고 만료 날짜를 선택하십시오.
5. **규칙 추가(Add rule)**를 선택하십시오.

사용 가능한 비교는 다음과 같습니다.

| 선택 | 의미 |
| --- | --- |
| `LessThan` | 가격이 임계값보다 `<` 낮음. |
| `LessThanOrEqual` | 가격이 임계값보다 `<=` 낮거나 같음. |
| `GreaterThan` | 가격이 임계값보다 `>` 높음. |
| `GreaterThanOrEqual` | 가격이 임계값보다 `>=` 높거나 같음. |
| `EqualTo` | 가격이 임계값과 정확히 같음. |
| `NotEqualTo` | 가격이 임계값과 다름. |

시작 경계는 해당 시각을 포함합니다. 만료 경계도 해당 시각을 포함하며, 지나면 규칙이 더 이상
발생하지 않습니다. SmartTicker는 시작보다 이른 만료를 거부합니다.

### 규칙이 발생할 때

활성화되고 예약 범위 안에 있는 규칙은 조건이 false에서 true로 바뀔 때 한 번 발생합니다.
조건이 계속 true인 동안 새로 고칠 때마다 알리지 않습니다. 가격이 조건을 벗어나면 규칙이
재설정되고 가격이 다시 조건에 들어올 때 발생할 수 있습니다.

규칙을 편집하거나 비활성화한 다음 다시 활성화해도 재설정됩니다. 따라서 가장 최근 정규 가격이
이미 조건을 만족하면 활성화된 규칙이 즉시 발생할 수 있습니다. 실패하거나 누락된 가격은 규칙을
발생시킬 수 없습니다.

하나 이상의 규칙이 발생하면:

- 해당 가격 항목이 구성된 기간 동안 구성된 경고 깜박임 색과 검은색을 번갈아 표시합니다.
  기본 깜박임 색은 자홍색(`#FF00FF`)입니다.
- **버즈(Buzz)**를 사용하면 SmartTicker가 구성된 버즈 시퀀스를 재생합니다.
- 경고 메시지는 규칙 하나를 식별하거나 함께 발생한 규칙 수를 보고합니다.
- 경고 강조 표시가 활성 상태여도 티커 스크롤은 계속됩니다.

### 경고 출력 설정

| 설정 | 범위 | 기본값 |
| --- | --- | --- |
| **버즈(Buzz)** | 켜기 또는 끄기 | 켜기 |
| 버즈 횟수(Buzz count) | 1~20 | 15 |
| **깜박임 기간(Blink for)** | 5~900초, 15초 단위 | 60초 |

버즈를 끄더라도 시각적 경고는 활성 상태로 유지됩니다. 같은 평가에서 여러 규칙이 발생하면
SmartTicker는 해당 평가에 대해 구성된 버즈 시퀀스를 하나만 시작합니다. **앱 설정 > 모양
(App Settings > Appearance)** 아래의 **경고 깜박임(Alert blink)**을 변경하십시오. 이는
애플리케이션 모양 기본 설정이므로 별도의 경고 규칙 파일 대신 설정 내보내기/가져오기에 포함됩니다.

### 구성된 규칙 관리

- **편집(Edit)**은 규칙을 양식에 불러옵니다. 저장하려면 **규칙 업데이트(Update rule)**를,
  변경하지 않으려면 **취소(Cancel)**를 선택하십시오.
- **사용 안 함(Disable)**은 규칙을 유지하지만 일치를 중지합니다. **사용(Enable)**은 규칙을
  재설정하고 최신 정규 가격을 기준으로 평가합니다.
- **제거(Remove)**는 규칙을 삭제합니다.
- 목록에는 활성화 상태, 종목 기호, 조건 요약 및 일정이 표시됩니다.

경고 규칙 변경과 경고 출력 설정은 자동으로 저장됩니다.

## 로컬 파일 및 개인 정보

SmartTicker는 구성을 로컬에 저장하고 개발자 서비스와 동기화하지 않습니다.

Windows의 기본 파일은 다음과 같습니다.

```text
%LocalAppData%\SmartTicker\settings.json
%LocalAppData%\SmartTicker\alerts.json
```

Linux에서 .NET은 일반적으로 다음과 같은 현재 사용자의 로컬 애플리케이션 데이터 디렉터리를
사용합니다.

```text
~/.local/share/SmartTicker/settings.json
~/.local/share/SmartTicker/alerts.json
```

### 격리된 데이터 디렉터리 사용

고급 진단 및 테스트 실행에서는 SmartTicker를 시작하기 전에 `SMARTTICKER_DATA_DIRECTORY`를
설정할 수 있습니다. 값이 비어 있지 않으면 두 파일 모두 확인된 디렉터리에 `settings.json`과
`alerts.json`으로 직접 배치되며 해당 프로세스에는 위의 플랫폼 기본값이 사용되지 않습니다.
절대 경로를 사용하는 것이 좋으며 쓰기 가능한지 확인하십시오.

PowerShell 예제:

```powershell
$env:SMARTTICKER_DATA_DIRECTORY = 'D:\SmartTicker-Profile'
& 'C:\Program Files\SmartTicker\SmartTicker.Desktop.exe'
```

Linux 셸 예제:

```bash
SMARTTICKER_DATA_DIRECTORY="$HOME/.local/share/SmartTicker-Test" smartticker
```

프로세스를 시작하기 전에 변수를 설정하십시오. SmartTicker는 기본 프로필을 선택한 디렉터리로
복사하지 않으므로 빈 디렉터리는 빈 구성으로 시작합니다. 같은 디렉터리를 가리키는 인스턴스는
서로의 저장된 편집을 감지할 수 있습니다. 백업 및 프로필 전송에는 일반 설정 및 경고 규칙
내보내기/가져오기 명령을 사용하십시오.

경고 창은 사용 중인 경고 파일의 정확한 경로를 표시합니다. 쓰기는 임시 파일을 사용한 후
교체하므로 일부만 기록된 파일이 현재 구성으로 처리되지 않습니다.

SmartTicker에는 계정, 원격 분석, 분석, 광고 또는 클라우드 동기화가 없습니다. SmartTicker가
소스를 요청하면 소스 웹사이트는 사용자의 IP 주소 같은 일반적인 네트워크 정보를 받습니다.
도움말을 열면 GitHub에서 원시 가이드를 요청합니다. 자세한 내용은 리포지토리의
`PRIVACY.md`를 참조하십시오.

각 소스 URL과 선택기를 웹사이트의 약관, 라이선스, robots 지시문 및 관련 법률에 따라 사용할
책임은 사용자에게 있습니다.

## 문제 해결

### 시세가 사용할 수 없음 또는 가격 없음으로 표시됨

소스 요청은 20초 후 시간 초과됩니다. 해당 시세에 이전의 성공한 스냅샷이 있으면 새로 고침에
실패해도 계속 표시됩니다. 그렇지 않으면 이후 새로 고침이 성공할 때까지 시세에 **사용할 수
없음(Unavailable)**이 표시됩니다. 선택기를 변경하기 전에 유효성 검사 또는 새로 고침 오류를
확인하십시오.

1. **시세... (Quotes...)**를 열고 항목을 편집한 다음 전체 URL(Full URL)을 확인하십시오.
2. **가격(Price)**이 선택되어 있는지 확인하십시오.
3. 메시지가 표시되면 웹사이트를 승인하십시오.
4. **URL 유효성 검사(Validate URL)**를 선택하고 정확한 결과를 읽으십시오.
5. **가격 검색(Discover price)**을 실행하거나 페이지의 정적 HTML을 검사하고 선택기를
   업데이트하십시오.
6. 페이지에 JavaScript, 인증 또는 SmartTicker가 안전하게 처리할 수 없는 동의가 필요한지
   확인하십시오.
7. HTTP 403, 429, robots 제한 및 사이트의 자동 액세스 정책을 준수하십시오.

### 장전 또는 시간외 데이터가 누락됨

- 해당 시장 세션이 활성 상태가 아닐 수 있습니다.
- 세션 값이 없을 때 페이지가 세션 요소를 생략할 수 있습니다.
- 장전 선택기는 장전 요소를, 시간외 선택기는 장후 요소를 대상으로 하는지 확인하십시오.
- 웹사이트 마크업이 변경되었을 수 있으므로 해당 검색 명령을 다시 실행하십시오.

### 뉴스가 비어 있음

- **뉴스(News)**가 선택되어 있는지 확인하십시오.
- 소스의 유효성을 검사하고 **뉴스 검색(Discover news)**을 실행하십시오.
- 선택기가 표시 가능한 헤드라인 텍스트가 있는 링크를 반환하는지 확인하십시오.
- 실패하거나 시간 초과된 뉴스 요청은 이전에 성공한 헤드라인이 있으면 계속 유지합니다. 성공한
  결과가 없는 소스는 이후 슬롯이 성공할 때까지 비어 있습니다.
- 헤드라인은 이 세션에 구성된 반복 제한에 도달하면 사라집니다.
- 정적 뉴스에서 원하는 시세가 **뉴스 표시 대상(Show news for)** 아래에 선택되어 있는지
  확인하십시오.

### 선택기 검색에서 아무것도 찾지 못함

검색은 다운로드한 정적 HTML만 읽습니다. 페이지 JavaScript가 나중에 생성하는 값은 볼 수
없습니다. 검증된 선택기를 직접 입력하거나, 정적 페이지/피드를 선택하거나, 호환되는 공개
페이지를 통해 승인되고 문서화된 API를 사용하십시오.

### 경고가 발생하지 않음

- 연결된 시세가 계속 존재하고 가격을 수집하며 정규 가격을 성공적으로 가져왔는지 확인하십시오.
- 규칙이 활성화(Enabled)되어 있고 시작/만료 일정 범위 안에 있는지 확인하십시오.
- 비교와 임계값을 확인하십시오. `EqualTo`는 정확한 소수 일치를 요구합니다.
- 계속 true인 조건은 한 번만 발생한다는 점을 기억하십시오. 규칙을 편집하거나 다시 활성화하지
  않는 한 다시 발생하려면 먼저 false가 되어야 합니다.
- 장전 및 시간외 가격은 경고 규칙을 실행하지 않습니다.

### SmartTicker를 이동하거나 크기를 조정할 수 없음

- 왼쪽 스트립의 세로 점 그립에서만 이동하십시오.
- 가장자리 또는 모서리에서 크기를 조정하십시오. 가장자리를 사용하기 어렵다면 오른쪽 아래의
  표시를 사용하십시오.
- 티커 콘텐츠는 의도적으로 이동 영역이 아닙니다.

### 정적 그룹 또는 값이 예상과 다름

- **시세... (Quotes...)**를 열고 각 항목의 그룹(Group) 값을 확인하십시오.
- **시세 그룹... (Quote groups...)**을 열어 그룹 정의를 관리하고 각 시세의 현재 연결을
  검토하십시오.
- 그룹이 비어 있는 항목은 **그룹 없음(Ungrouped)** 아래에 나타납니다.
- **변동(Chg)**은 Last와 Chg%에서 계산되며 페이지에서 독립적으로 추출되지 않습니다. 백분율을
  사용할 수 없으면 `—`로 유지됩니다.
- 위/아래 컨트롤로 항목 순서를 변경하여 그룹 및 행 순서를 바꾸십시오.
- 타일 머리글의 점선 핸들을 끌어 전체 그룹을 이동하십시오. 다른 타일의 왼쪽 절반에 놓으면 그
  앞에, 오른쪽 절반에 놓으면 그 뒤에 배치됩니다.
- SmartTicker가 일시 중지되지 않았을 때 **지금 가격 새로 고침(Refresh prices now)**을
  선택하여 표를 업데이트하십시오.

### 도움말 텍스트에 서식이 없거나 탐색이 이동하지 않음

- 도움말 창은 Markdown 문장 부호 대신 서식이 지정된 머리글, 단락, 목록, 표, 링크 및 코드
  블록을 표시해야 합니다.
- 왼쪽의 **이 페이지에서(On this page)**를 사용하여 주요 섹션으로 이동하십시오. 빠른 탐색
  표의 링크도 문서 안에서 스크롤됩니다.
- 도움말을 닫았다가 다시 열거나 **언어(Language)**를 변경하여 해당하는 게시된 가이드를
  요청하십시오. 가이드를 가져오는 동안 SmartTicker는 설치된 애플리케이션에 포함된
  서식 지정된 가이드를 표시합니다.

### 온라인 도움말을 사용할 수 없거나 오래됨

- 도움말을 닫았다가 다시 열어 게시된 가이드를 다시 요청하십시오.
- 이 가이드의 앞부분에 표시된 원시 GitHub 주소를 브라우저에서 열어 게시된 파일을 직접
  확인하십시오.
- 요청이 실패하거나 빈 파일을 반환하면 SmartTicker가 포함된 가이드를 사용합니다.
- 온라인 변경 내용은 `HELPME.md` 또는 해당하는 `help/HELPME.<language-code>.md`가
  리포지토리의 `main` 분기에 게시된 후에만 나타납니다.
