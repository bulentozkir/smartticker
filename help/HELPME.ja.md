# SmartTicker ヘルプ

このガイドは SmartTicker 1.0.3 を対象としています。メインティッカー、アプリ設定
(App Settings)、株価 (Quotes)、アラートルール、ウェブサイトのアクセス許可、
バックアップ、および一般的な問題について説明します。

SmartTicker は、ユーザーが構成したウェブページから公開されている静的 HTML を
読み取ります。市場データフィードは提供しません。また、抽出された情報には遅延、
欠落、誤りが含まれる可能性があります。重要な金融情報は信頼できる情報源で確認して
ください。

## ヘルプと設定ウィンドウを開く

ティッカーを右クリックしてメニューを開きます。主な設定コマンドは次のとおりです。

- **株価... (Quotes...)**: 株価またはニュースのソースを追加、テスト、編集、並べ替え、
  削除します。
- **株価グループ... (Quote groups...)**: グループを作成、更新、削除し、株価を関連付けます。
- **アラート (Alerts)**: 価格アラートルールを作成および管理します。
- **アプリ設定... (App Settings...)**: 行数、速度、更新間隔、スタートアップ、
  ウェブサイトへのアクセス、色、透明度、バックアップを設定します。
- **表示 (View)**: スクロールまたは静的表示と、価格のみまたは価格とニュースを
  組み合わせた、相互に排他的な 4 つの選択肢から 1 つを選びます。
- **ヘルプ (Help)**: SmartTicker 内でこのガイドを開きます。
- **SmartTicker について (About SmartTicker)**: インストール済みのバージョンと
  ライセンス通知を表示します。
- **終了 (Exit)**: SmartTicker を完全に終了します。

ヘルプウィンドウは、選択中のアプリ言語の組み込みガイドを直ちに書式設定して表示し、
ヘルプを開くか **言語 (Language)** を変更するたびに、その言語に対応するオンライン
ガイドを確認します。日本語のオンラインガイドは次のとおりです。

<https://raw.githubusercontent.com/bulentozkir/smartticker/refs/heads/main/help/HELPME.ja.md>

翻訳版ガイドは、同じリポジトリの `help/HELPME.<language-code>.md` を使用します。
オンライン文書をダウンロードできない場合、SmartTicker はインストール済み
アプリケーションに組み込まれた対応する翻訳版を表示し続けます。
**言語 (Language)** を変更すると、開いているヘルプのタイトル、ステータス、
ナビゲーション、およびガイド全体が直ちに更新されます。ヘルプを閉じるには、
タイトルバーの通常の閉じるボタンを使用します。

## メインティッカーの操作

### スクロール表示または静的な株価表示を選択する

SmartTicker には、相互に排他的な 4 つの表示モードがあります。ティッカーを右クリックし、
**表示 (View)** を開いて 1 つ選択します。レイアウトはすぐに変更され、選択内容が保存されます。

| 表示オプション | 結果 |
| --- | --- |
| **左から右へスクロール: 価格のみ (Left-to-right scroll: Prices only)** | メインティッカーに価格マーキーを表示し、ニュースは表示しません。これが既定値です。 |
| **左から右へスクロール: 価格とニュース (Left-to-right scroll: Prices with News)** | メインティッカーに価格とニュースのマーキーを表示します。 |
| **静的表示: 価格のみ (Static view: Prices only)** | メインウィンドウにレスポンシブな価格タイルを表示し、ニュースウィンドウは表示しません。 |
| **静的表示: 価格とニュース (Static view: Prices with News)** | レスポンシブな価格タイルに加え、独立した静的な **SmartTicker News** ウィンドウを表示します。 |

これらの選択肢が追加される前に作成された設定ファイルは、保存済みのスクロール/静的表示と
ニュース設定に対応する組み合わせへ移行されます。表示モードは、ティッカーの右クリック
**表示 (View)** メニューからのみ管理します。

- どちらのスクロールモードでも、価格には横方向のマーキーと、設定された価格の行数および
  スクロール速度が使用されます。
- どちらの静的モードでも、グループは左から右に並ぶレスポンシブなタイルとして表示されます。
  ウィンドウが狭すぎる場合にのみタイルが次の行へ折り返されます。価格は自動的には移動しません。
- 各株価タイルには、整列した **シンボル (Symbol)**、**終値 (Last)**、**変化量 (Chg)**、
  **変化率 (Chg%)** の列があります。ソースページには絶対変化量用の独立したセレクターではなく
  パーセント用セレクターがあるため、**変化量 (Chg)** は Last と Chg% から算出されます。
  どちらかの値を利用できない場合は `—` と表示されます。
- グループ見出しを選択すると、グループを折りたたんだり展開したりできます。グループは、
  構成済み項目の順序で、その株価が最初に現れる位置に従います。グループ内の行もその順序を保ちます。
- グループのない項目は **グループなし (Ungrouped)** に表示されます。
- Last にポインターを合わせると、利用可能なプレマーケット値と時間外取引値を確認できます。
  株価行をダブルクリックすると、そのソースページが開きます。
- アラートの点滅と上昇/下降の色は、どちらの価格モードでも機能します。
- ニュースは、静的な **シンボル / 見出し (Symbol / Headline)** グループタイルを含む独立した
  **SmartTicker News** ウィンドウで自動的に開きます。静的モードではマーキー表示されません。
  ニュースウィンドウには通常のタイトルバーとサイズ変更枠があるため、株価ウィンドウとニュース
  ウィンドウを別々のモニターへ個別に移動できます。見出し行をダブルクリックするとソースが開きます。
- 初回起動時、ニュースにはコンパクトな 680×340 のサイズが使用されます。別のモニターがあれば、
  SmartTicker はそこへ配置します。モニターが 1 台の場合は、まず価格ウィンドウの下、右、上、左の
  空き領域を順に試します。その後は通常どおり移動およびサイズ変更できます。
- 各ニュースグループ内では、見出しが株価ごとに交互に配置されます。最初の株価から 1 件、次の
  株価から 1 件というように巡回します。そのため、見出しが多い 1 つの株価がグループ上部を
  すべて占有することはありません。
- 1 行の **ニュースの表示対象 (Show news for)** ドロップダウンを開き、各株価を個別にオンまたは
  オフにします。すべて、なしを含む任意の組み合わせを表示できます。ボタンには現在の選択内容が
  要約され、項目には株価とソースが含まれるため、同じシンボルでも独立したままです。オフにした
  株価は設定ファイルの `hiddenNewsQuotes` に保存されるため、再起動後も維持され、設定の
  バックアップにも含まれます。
- 株価またはニュースタイルの見出し横にある点線のハンドルをドラッグし、別のタイルの左半分または
  右半分にドロップします。両方のウィンドウで順序が変わり、元の構成済み項目を並べ替えることで
  保存されます。
- 行数の多いグループは、境界のある独自のタイル内でスクロールします。折り返されたタイル行が
  現在のウィンドウ高さに収まらない場合にのみ、ビュー全体が縦にスクロールします。

**SmartTicker News** を閉じても、ニュース収集は無効になりません。再度開くには、価格ウィンドウを
右クリックし、**表示 > 静的ニュースウィンドウを開く (View > Open static news window)** を選択します。
**静的表示: 価格のみ (Static view: Prices only)** を選ぶと閉じ、**静的表示: 価格とニュース
(Static view: Prices with News)** を選ぶと再び開きます。どちらのスクロール表示を選んでも独立した
ニュースウィンドウは閉じます。価格とニュースのスクロール表示を選ぶと、メインティッカーの
ニュースマーキーが復元されます。

モードを切り替えると、そのビュー用に保存されたサイズが適用されます。スクロールティッカー、
静的な価格ウィンドウ、静的なニュースウィンドウは、それぞれ独立した幅と高さを保持します。

### ティッカーを移動する

左側の細い帯の上部にある縦の点で示されたグリップを押したままティッカーをドラッグし、
マウスボタンを放します。ティッカーのテキストはドラッグ領域ではないため、内容を選択したり
クリックしたりしても、誤ってウィンドウの移動が始まることはありません。

### ティッカーのサイズを変更する

サイズ変更カーソルが表示されるまでポインターを任意の辺または角へ移動し、押したままドラッグします。
右下隅には小さなサイズ変更マークがあります。ウィンドウの最小幅は 420 ピクセルです。スクロール
表示の高さは 50 から 900 ピクセル、静的な価格の高さは 420 から 4320 ピクセル、静的なニュースの
高さは 240 から 4320 ピクセルです。

手動でサイズを変更すると、ドラッグ操作が落ち着いた後、アクティブなビュー用に保存された寸法が
更新されます。3 組のサイズはすべて設定バックアップに含まれます。ウィンドウ位置は保存されません。
スクロール表示の高さが、選択した価格/ニュース行とスクロール文字サイズに対して足りない場合、
SmartTicker は保存された高さを自動的に増やします。そのため **左から右へスクロール: 価格とニュース
(Left-to-right scroll: Prices with News)** を選択すると、ニュース行を黙って隠すことなく、常に必要な
領域が確保されます。
ウィンドウが開くか移動するたびに、SmartTicker は左上の 32 ピクセル四方の角を少なくとも 1 つの
画面の作業領域内に保ち、グローバル X と Y を 1 以上に制限します。これにより、モニターを切断した
後でも、移動グリップまたはタイトルの角へマウスで到達できます。

### 一時停止と再開

移動グリップの下にあるステータスボタンを選択するか、右クリックして **一時停止 / 再開
(Pause / Resume)** を選択します。一時停止すると、価格とニュースの自動更新が止まり、マーキーが
停止します。また、どちらの手動更新コマンドも新しい処理を開始できなくなります。一時停止した時点で
すでに進行中のソース要求は、それだけを理由に強制キャンセルされないため、動作が完全に落ち着く前に
完了する場合があります。再開すると自動タイマーが再始動します。

Windows では、SmartTicker は UI を起動する前に OS プロセス優先度を自動的に **低 (Low)** に設定し、
Windows の **効率モード (Efficiency mode)** (EcoQoS) を有効にします。この動作を変更するアプリ設定は
ありません。また、オーバーヘッドの少ないソフトウェアレンダリング経路を使用します。マーキーの
タイミングは設定された速度に適応し、一時停止中、空、またはデタッチされたマーキーはアニメーション
タイマーを停止します。変化していない行では冗長な視覚通知を抑制します。アラートの点滅と 3 秒間の
茶色い変更強調表示は意図された動作であり、スクロールを一時停止しません。Linux のプロセス
スケジューリングはオペレーティングシステムに委ねられます。Windows がどちらかのプロセス設定を
拒否した場合、SmartTicker は診断トレースにエラーを記録し、起動を続行します。

### リンクを開く

ニュース見出しを含むリンク付きティッカーテキストをダブルクリックすると、既定のブラウザーで
ソースが開きます。SmartTicker はシングルクリックではリンクを開きません。

### 変更箇所の強調表示

更新のたびに、SmartTicker は変化した箇所を 3 秒間、茶色の背景で一時的に示します。

- 前回の同期と価格が異なる株価。
- その株価について前回の同期には存在しなかった各見出し。

起動後の最初の同期では比較対象となる以前の値がないため、何も強調表示されません。発動した
アラートは独自のアラート点滅色を維持し、ほかの強調表示より優先されます。

### メインメニュー一覧

| コマンド | 効果 |
| --- | --- |
| **価格を今すぐ更新 (Refresh prices now)** | 段階的な価格サイクルを再開し、SmartTicker が一時停止していないときに最初の時間枠を要求します。 |
| **ニュースを今すぐ更新 (Refresh news now)** | 段階的なニュースサイクルを再開し、SmartTicker が一時停止していないときに最初の時間枠を要求します。 |
| **一時停止 / 再開 (Pause / Resume)** | 更新とマーキーの移動を切り替えます。 |
| **表示 > 左から右へスクロール: 価格のみ (View > Left-to-right scroll: Prices only)** | 横方向の価格マーキーのみを使用します。これが既定値です。 |
| **表示 > 左から右へスクロール: 価格とニュース (View > Left-to-right scroll: Prices with News)** | 両方の横方向マーキーを使用します。 |
| **表示 > 静的表示: 価格のみ (View > Static view: Prices only)** | レスポンシブな静的株価タイルのみを使用します。 |
| **表示 > 静的表示: 価格とニュース (View > Static view: Prices with News)** | 株価タイルと独立した静的ニュースウィンドウを使用します。 |
| **表示 > 静的ニュースウィンドウを開く (View > Open static news window)** | 閉じた独立ニュースウィンドウを再度開きます。ニュースが有効な静的モードで使用できます。 |
| **言語 (Language)** | メニュー、ステータステキスト、および完全なヘルプガイドに使用する 16 言語のいずれかを選択します。開いているヘルプウィンドウは直ちに更新されます。 |

行の表示状態、言語、およびその他の設定値は自動的に保存されます。

## 株価

右クリックメニューから **株価... (Quotes...)** を開きます。構成済みの各項目は、1 つのシンボルと
1 つのウェブページを表します。同じシンボルも許可され、各項目が独自のソース、セレクター、収集
オプション、アラートを持つため、それぞれ独立したままです。

### 公開サンプルですぐに始める

項目が存在しない場合、株価ウィンドウに **GitHub からサンプル株価をインポート
(Import sample quotes from GitHub)** が表示されます。これはリポジトリのサンプルをダウンロードし、
現在のアプリケーション設定を置き換えます。使用する前に、インポートされた各 URL と各ウェブサイトの
現在の利用規約を確認してください。サンプル項目は後から編集または削除できます。

株価ウィンドウとアプリ設定ウィンドウの上部にある **サンプル株価構成をインポート
(Import Sample Quotes Config)** でも、確認後にいつでも同じ操作を実行できます。

- SmartTicker は **よろしいですか? (Are you sure?)** と確認し、ダウンロードによって既存の株価、
  株価グループ、ソース承認、表示、外観、およびその他のアプリ設定が置き換えられることを警告します。
  アラートルールは独自のファイルに保存されており、削除されません。
- **既存の構成をエクスポート... (Export existing config...)** は省略できます。現在の構成をローカルの
  JSON ファイルに保存してから、同じ確認画面に戻ります。
- **サンプル株価構成をインポート (Import Sample Quotes Config)** はインターネットからサンプルを
  ダウンロードし、構成を置き換えます。
- **キャンセル (Cancel)** は何も変更しません。

### 株価またはニュース項目を追加する

1. `MSFT` などの **ティッカー (Ticker)** ラベルを入力します。SmartTicker は前後の空白を削除し、
   大文字で保存します。
2. 必要に応じて検索候補から既存の **グループ (Group)** を選ぶか、`Nasdaq`、
   `Precious Metals`、`Mag 7` などの新しい名前を入力します。**グループなし (Ungrouped)** にするには
   空のままにします。
3. **ソース (Source)** プリセットを選択します。
4. **URL サフィックス (URL suffix)** を入力します。**カスタム URL (Custom URL)** を使用する場合は、
   完全な URL を入力します。
5. **収集 (Collect)** で **価格 (Price)**、**ニュース (News)**、または両方を選択します。少なくとも
   1 つが必要です。
6. セレクターを手動で入力するか検出ボタンを使用します。省略可能なセレクターを空のままにすると、
   組み込み検出が使用されます。
7. **URL を検証 (Validate URL)** を選択し、通常価格や見出しをテストします。
8. SmartTicker がソースの承認を求めた場合はウェブサイトを確認し、データ収集を許可されている場合に
   のみ承認します。
9. **独立した項目を追加 (Add independent entry)** を選択します。SmartTicker は項目を保存し、
   有効なデータを直ちに更新します。

### 株価をグループ化する

グループは、ユーザーが定義する名前付きコレクションです。取引所や組み込みカテゴリには関連付けられて
いないため、市場、資産の種類、戦略、ポートフォリオ、地域、その他任意の方法で項目を整理できます。
名前の前後の空白は削除され、Unicode を使用でき、最大 80 文字です。各株価が属せるグループは
最大 1 つです。

グループフィールドの横にある **グループを管理 (Manage groups)** を使用するか、ティッカーの
右クリックメニューから **株価グループ... (Quote groups...)** を選択します。ウィンドウには 3 つの
作業領域があります。

- 左側で **グループ名 (Group name)** を入力し、**作成 (Create)** を選択します。既存のグループを
  選び、名前を編集して **更新 (Update)** を選ぶか、**削除 (Delete)** を選びます。空のグループも
  保持されます。
- 右側で株価を選択します。現在のグループは **現在のグループ (Current group)** 列に表示されます。
  **グループなし (Ungrouped)** は関連付けがないことを示します。
- 中央で、グループと株価を 1 つずつ選んだ後、**関連付け (Associate)** を選択します。その株価が
  すでに別のグループに属している場合、SmartTicker は選択したグループへ移動します。
- **関連付けを削除 (Remove association)** を選択すると、選択した株価だけが **グループなし
  (Ungrouped)** に戻ります。
- グループを削除すると、そのグループのすべての株価が **グループなし (Ungrouped)** に戻ります。
  株価、ソース、現在のデータ、アラートは削除されません。
- 株価を追加または編集するときに、検索候補から既存のグループを選ぶか、新しいグループ名を入力する
  こともできます。
- 構成済み項目 (Configured entries) の上下ボタンを使用して、静的テーブルのグループと行の順序を
  決めます。
- 静的モードでは、タイル見出しをドラッグしてグループ全体を直接並べ替えます。同じ順序が独立した
  株価ウィンドウとニュースウィンドウで使用されます。

公開サンプルには 6 つのサンプルグループが含まれますが、静的モードは既定でオフです。インポート後に
静的表示を有効にすると、それらのグループがテーブルとして表示されます。

### ソースのプリセットと URL

| ソース | 入力内容 | SmartTicker が表示するポリシー |
| --- | --- | --- |
| **Yahoo Finance** | `https://finance.yahoo.com/` より後のサフィックス。例: `quote/MSFT/`。 | 書面による許可が必要です。Yahoo の規約では、事前の許可なしで自動収集することを禁止しています。 |
| **CNBC** | `https://www.cnbc.com/` より後のサフィックス。 | サイトの現在のポリシーと robots ディレクティブを確認してください。 |
| **Trading Economics** | `https://tradingeconomics.com/` より後のサフィックス。 | 文書化された API または承認済みフィードを優先し、サイトの現在のポリシーを確認してください。 |
| **カスタム URL (Custom URL)** | 公開 `http://` または `https://` ページの完全な URL。 | サイトの利用規約、プライバシーポリシー、自動アクセス規則を確認してください。 |

絶対形式の HTTP URL と HTTPS URL のみ使用できます。ユーザー名またはパスワードが埋め込まれた URL は
拒否されます。ブラウザーへのログインによって SmartTicker にページ収集の権限が付与されるわけでは
なく、SmartTicker は認証済みブラウザーセッションを使用しません。

**完全な URL (Full URL)** の行には、プリセットのプレフィックスと入力したサフィックスから生成された
最終アドレスが表示されます。検証または検出の前に確認してください。

### 収集オプション

- **価格 (Price)** は通常価格を要求します。省略可能な変化率、プレマーケット、時間外取引の
  セレクターは、同じダウンロード済みページで評価されます。
- **ニュース (News)** はページから見出しリンクを要求します。
- 両方を選ぶと、1 つの項目がティッカーの両方の領域にデータを提供できます。
- 両方をオフにすることはできません。

### セレクターフィールド一覧

CSS セレクターは、ウェブページの静的 HTML 内にある要素を識別します。自動検出で必要な値が見つからない
場合を除き、セレクターは省略できます。

| フィールド | SmartTicker が抽出する値 |
| --- | --- |
| **価格セレクター (Price selector)** | 通常価格または終値。 |
| **価格変化率 (Price change)** | 通常取引時間の変化率。空の場合、組み込みの変化率検出を試みます。 |
| **プレマーケットセレクター (Pre-market selector)** | ページにその取引時間が存在する場合のプレマーケット価格。 |
| **プレマーケット変化率 (Pre-market change)** | プレマーケットの変化率。 |
| **時間外セレクター (After-hours selector)** | 取引終了後または時間外取引の価格。 |
| **時間外変化率 (After-hours change)** | 取引終了後または時間外取引の変化率。 |
| **ニュースセレクター (News selector)** | 見出しリンク。アンカー、またはリンクを含む結果を返すコンテナーを選択します。 |

プレマーケット値と時間外取引値は通常価格を補足するものであり、置き換えるものではありません。
対応する市場セッション外では、ページにこれらの要素が存在しない場合があります。

公開サンプルで使用される Yahoo Finance セレクターの例は次のとおりです。

```text
Price:                  [data-testid="qsp-price"]
Price change:           section.primary span[data-testid="qsp-price-change-percent"]
Pre-market price:       section.secondary span[data-testid="qsp-pre-price"]
Pre-market change:      section.secondary span[data-testid="qsp-pre-price-change-percent"]
After-hours price:      section.secondary span[data-testid="qsp-post-price"]
After-hours change:     section.secondary span[data-testid="qsp-post-price-change-percent"]
```

ウェブサイトのマークアップは時間とともに変化します。例は出発点として扱い、永続的な仕様とは
見なさないでください。

### セレクターを検出する

各セレクターフィールドには、対応する **検出 (Discover)** ボタンがあります。

1. ソース URL を完成させ、承認が必要な場合はウェブサイトを承認します。
2. 正確な値の種類に対応する検出ボタンを選択します。
3. SmartTicker は公開されている静的 HTML をダウンロードし、候補セレクターをサンプル値、信頼度、
   理由とともにツールチップへ一覧表示します。
4. 候補の横にある **使用 (Use)** を選択し、対応するフィールドへコピーします。
5. 使用を決める前に、結果を検証または観察します。

検出機能は JavaScript を実行せず、サインインせず、アクセス制御を回避せず、ブラウザーを調べません。
JavaScript だけで生成される値には検出可能なセレクターがない場合があります。検出の種類を分けることで、
プレマーケット値と時間外取引値が意図的に混在しないようにしています。

### ソースを検証する

**URL を検証 (Validate URL)** はページを要求し、読み取れる通常価格や見出し数を報告します。
SmartTicker はテスト用の一時ラベルを使用するため、ティッカーを入力する前でも安全に使用できます。

現在、この検証ではプレマーケットと時間外取引の 4 つのセレクターフィールドを確認しません。
検出時のサンプル値を使い、その後で表示されたセッションデータを確認してください。

一般的な失敗には、HTTP エラー、タイムアウト、値の欠落、見出し数 0、ソースの未承認、
JavaScript のみのコンテンツ、古いセレクターがあります。

### ニュースの繰り返し上限

**最大 _N_ 回表示 (Show max _N_ times)** には 1 から 100 を指定でき、既定値は 5 です。SmartTicker は、
同じ見出しタイトルが返されたニュース更新サイクルが完了するたびに 1 回と数えます。タイトルが設定した
回数のサイクルに表示されると、現在のアプリケーションセッションが終了するまで表示対象から除外されます。
その項目を編集または削除すると、繰り返し履歴は消去されます。

### 項目を編集、並べ替え、削除する

**構成済み項目 (Configured entries)** の一覧には、シンボル、グループ、ソース、URL、収集バッジ、
通常価格セレクター、ニュースセレクター、ニュースの繰り返し上限が表示されます。

- **編集 (Edit)** は項目をフォームへ読み込みます。適用するには **変更を保存 (Save changes)**、
  フォームの変更を破棄するには **編集をキャンセル (Cancel edit)** を選択します。
- 上下の矢印ボタンはティッカーの順序を変更し、すぐに保存します。
- **削除 (Remove)** は項目と現在表示されているデータを削除します。
- アラートルールがその項目を対象としている場合、SmartTicker はルールも削除するか確認します。
  一致する構成済み株価のないアラートは発動できません。
- 項目名を変更すると、その項目に関連付けられたルールの表示シンボルも更新されます。

## アプリ設定

右クリックメニューから **アプリ設定... (App Settings...)** を開きます。変更は直ちに反映および保存され、
適用 (Apply) ボタンはありません。

### ティッカーの行数と速度

| 設定 | 選択肢 | 既定値 | 効果 |
| --- | --- | --- | --- |
| 価格行 (Price rows) | 1 から 8 | 1 | 並列に表示する価格マーキーの行数。 |
| 価格スクロール速度 (Price scroll speed) | 20、30、40、50、65、80、100、120 px/sec | 50 | 価格マーキーの速度。 |
| ニュース行 (News rows) | 1 から 8 | 1 | 並列に表示する見出しマーキーの行数。 |
| ニューススクロール速度 (News scroll speed) | 20、30、40、50、65、80、100、120 px/sec | 40 | ニュースマーキーの速度。 |
| スクロール文字サイズ (Scrolling font size) | 9 から 24 pt | 14 pt | スクロール行の価格およびニューステキスト。 |
| 静的文字サイズ (Static font size) | 9 から 24 pt | 13 pt | 静的行の株価および見出しテキスト。 |
| 価格更新 (Price refresh) | 30 から 300 秒、15 秒単位 | 60 秒 | 許可されたすべての価格項目が 1 回の予定更新を受けるまでの時間。 |
| ニュース更新 (News refresh) | 30 から 300 秒、15 秒単位 | 300 秒 | 許可されたすべてのニュース項目が 1 回の予定更新を受けるまでの時間。 |

静的なグループテーブルがアクティブな間は、価格行と価格スクロール速度が無効になります。このモードでは
すべての価格項目を表示し、どちらのウィンドウも自動スクロールしないためです。ニュースの行数と速度の
設定はスクロール表示用に保持されます。

価格とニュースの要求は、同時に開始するのではなく、それぞれの間隔全体にわたる 1 秒の時間枠へ独立して
分散されます。たとえば、30 秒に 60 項目なら 1 秒あたり 2 項目、30 秒に 5 項目なら約 6 秒ごとに
1 項目が予定されます。同時に実行されるソース要求は最大 4 件です。同じ項目とストリームの重複処理は
省略され、逃した時間枠が一度にまとめて再実行されることはありません。**価格を今すぐ更新
(Refresh prices now)** または **ニュースを今すぐ更新 (Refresh news now)** は、そのストリームだけを
再開し、最初の時間枠を要求します。代替データの読み取り中も、以前に正常取得した価格と見出しは表示されます。

各 HTTP 要求には固定の 20 秒タイムアウトがあります。遅いソースが UI ディスパッチャーを占有したり、
後続の時間枠が残りの要求容量を使用できなくなったりすることはありません。SmartTicker は HTTP 403 や
429 などの失敗を報告し、制限を回避しません。robots ディレクティブ、crawl-delay 値、サーバーの
バックオフ指示を自動的に解析または適用しないため、準拠したソースを選び、不必要に頻繁な要求を避けて
ください。

### ウィンドウサイズ

アプリ設定には、独立した 3 組のサイズが保存されます。

| ウィンドウ | 幅 | 高さ | 既定値 |
| --- | --- | --- | --- |
| スクロール表示 | 420–7680 px | 50–900 px | 980 × 64 px |
| 静的な価格表示 | 420–7680 px | 420–4320 px | 980 × 420 px |
| 静的なニュース表示 | 420–7680 px | 240–4320 px | 680 × 340 px |

値を変更すると、そのウィンドウまたはビューがアクティブな場合はすぐに適用されます。公開サンプルでは、
スクロール表示に 1200 × 96、静的な価格に 1200 × 720、静的なニュースに 760 × 480 を使用し、
スクロールテキストは 15 ポイント、静的テキストは 14 ポイントです。有効な行に必要な領域を下回る
スクロール高さは、必要な最小値まで自動的に増やされます。

**表示 (View)** の 4 つの選択肢を使用して、ニュースを表示するか、およびレイアウトをスクロール表示に
するか静的表示にするかを選択します。表示を変更しても、構成済み項目が削除されることはありません。

### サインイン時に SmartTicker を起動する

**サインイン時に SmartTicker を起動 (Start SmartTicker when I sign in)** を有効にすると、インストール
済みの実行可能ファイルが現在のユーザーだけに登録されます。

- Windows では、SmartTicker は現在のユーザーの `Run` レジストリキーを使用します。
- freedesktop の自動起動規則に対応する Linux デスクトップでは、SmartTicker はユーザーの自動起動
  ディレクトリに `smartticker.desktop` を書き込みます。
- SmartTicker に対応する登録方法がないプラットフォームでは、このオプションは無効になります。

オペレーティングシステムが正となります。SmartTicker の外部でスタートアップを変更した場合、次に設定を
読み込んだときにチェックボックスへ OS の状態が反映されます。

### ウェブサイトへのアクセス

**ウェブサイトの Cookie とホスト間リダイレクトを許可 (Allow website cookies and cross-host redirects)** は
既定で無効です。

無効の場合:

- SmartTicker は、各ウェブサイトホストを要求する前に、そのホストに対する明示的な承認を 1 回求めます。
- ウェブサイトの Cookie は受け入れません。
- 別のホストへのリダイレクトはブロックされます。
- 承認済みホストはローカル設定に記憶されます。

有効の場合:

- SmartTicker はホストごとの承認手順を省略します。
- 要求先のウェブサイトが設定した Cookie は、分離されたメモリ内コンテナーだけに保持され、SmartTicker
  の終了時に消去されます。
- 他のホストへのリダイレクトをたどる場合があります。
- SmartTicker がブラウザーの Cookie を読み取ったり、資格情報やサインインフォームを送信したりする
  ことは引き続きありません。

このオプションを無効に変更すると、未承認ソースから現在表示されているデータは、それらのホストが承認、
更新されるまで削除されます。

#### ウェブサイトのプライバシー選択

肯定と否定の両方の選択肢を含むプライバシー/Cookie フォームとして応答が認識されると、SmartTicker は
一時停止し、ページタイトル、要求 URL、同意 URL、フォーム概要、ウェブサイトの承諾/拒否
(Accept/Reject) ラベルを表示します。

- **承諾 (Accept)** は、フォームが提供した非表示フィールドと、選択した正確な承諾コントロールを
  送信します。
- **拒否 (Reject)** は、その非表示フィールドと、選択した正確な拒否コントロールを送信します。
- **キャンセル (Cancel)** は何も送信しません。

これはウェブサイトのプライバシー選択であり、SmartTicker のソースごとのアクセス許可承認ではありません。

#### すべてのソースを検証する

**すべてのソースを検証 (Validate all sources)** を選択し、構成済みの全項目を確認およびテストします。

1. ウェブサイトへのアクセスが制限されている場合、SmartTicker は未承認の項目をホスト名別にまとめ、
   ホストごとに 1 つのソース確認ダイアログを表示します。
2. ホスト、ポリシー概要、ガイダンス、ソース名、シンボルを確認します。
3. ウェブサイトを確認し、使用を許可されている場合にのみ確認ボックスをオンにします。
4. **このソースを承認 (Approve this source)**、**このソースをスキップ (Skip this source)**、または
   **検証をキャンセル (Cancel validation)** を選択します。
5. SmartTicker は許可された各項目をテストし、成功、失敗、スキップの合計を報告します。個別の問題は
   ステータス行の下に表示されます。

承認レコードは SmartTicker 内にアクセス許可を記録します。法的な権利を付与したり、ウェブサイトの
規約に優先したりするものではありません。

### 外観

**ウィンドウの透明度 (Window transparency)** はティッカーの背景だけを変更します。テキストは不透明の
ままです。範囲は 20% から 100% まで 5% 単位で、既定値は 100% です。

色フィールドには `#RRGGBB` 形式の 16 進値を指定でき、カラーピッカーも使用できます。

| 色 | 既定値 | 使用箇所 |
| --- | --- | --- |
| 背景 (Background) | `#10151D` | 透明度が適用される前のティッカー背景。 |
| 株価名 (Quote name) | `#79C0FF` | シンボル/ソースラベル。 |
| 終値 (Close price) | `#FFA657` | 通常価格。 |
| 時間外 (After hours) | `#00E5FF` | プレマーケット価格と時間外取引価格。 |
| ニュース 1 番目 (News 1st) | `#FFFFFF` | 1、5、9 番目などの見出し。 |
| ニュース 2 番目 (News 2nd) | `#00E5FF` | 2、6、10 番目などの見出し。 |
| ニュース 3 番目 (News 3rd) | `#A3E635` | 3、7、11 番目などの見出し。 |
| ニュース 4 番目 (News 4th) | `#79C0FF` | 4、8、12 番目などの見出し。 |
| 上昇 (Change up) | `#3FB950` | 正の変化率。 |
| 下降 (Change down) | `#F85149` | 負の変化率。 |
| アラート点滅 (Alert blink) | `#FF00FF` | 発動した価格アラート。黒と交互に表示。 |

**既定値に戻す (Reset to defaults)** は、上記のすべての色と背景の不透明度 100% を復元します。
行数、速度、文字サイズ、ウィンドウサイズ、ソース、更新間隔、アラート、言語はリセットしません。

### バックアップと復元

SmartTicker はアプリケーション設定とアラートルールを別々の JSON ファイルに保存し、バックアップの
種類ごとに独立したボタンを提供します。

#### 設定をエクスポートおよびインポートする

- **設定をエクスポート... (Export settings...)** は、構成済み項目、グループの割り当て、グループ定義、
  非表示ニュース株価、項目順序、セレクター、株価のスクロール/静的表示の選択、承認済みホスト、行の
  表示状態、行数、速度、スクロール/静的文字サイズ、3 組すべてのウィンドウサイズ、更新間隔、
  スタートアップ設定、ウェブサイトアクセス設定、アラート点滅色を含む色、透明度、言語を書き出します。
- **設定をインポート... (Import settings...)** は、何も変更する前にファイル全体を検証します。
  拒否されたファイルでは、現在の設定は変更されません。
- インポートに成功すると、構成済みの全項目とアプリケーション設定が置き換えられます。独立した
  アラートルールファイルは置き換えられません。
- グループは、グループ定義自体に加えて株価の割り当てとしても設定ファイルに含まれるため、株価のない
  グループもバックアップに残ります。グループだけをエクスポートまたはインポートする独立ファイルは
  ありません。
- スタートアップ設定は設定バックアップに含まれますが、インポートによって OS のスタートアップ登録が
  自動的に変更されることはありません。オペレーティングシステムが正となります。現在のコンピューターで
  登録を変更するには、スタートアップ (Startup) チェックボックスを使用します。
- インポートファイルは 1 MiB、スキーマバージョン 1、最大 200 サブスクリプションに制限されます。
  不明なプロパティ、重複 ID、不正な URL、無効な色、範囲外の値、未対応の言語コードは無視されず、
  拒否されます。

#### アラートルールをエクスポートおよびインポートする- **アラートルールをエクスポート... (Export alert rules...)** は、すべてのルールに加えて、Buzz、ブザー回数、点滅時間を書き出します。
- **アラートルールをインポート... (Import alert rules...)** はファイル全体を検証してから、現在の
  すべてのルールとアラート発動設定を置き換えます。
- ルールは最初にサブスクリプション ID で再接続されます。ID が異なる場合、SmartTicker は大文字と
  小文字を区別せずにシンボルの一致を試みます。
- 対応する株価のないインポート済みルールも保持されますが、発動できません。インポートステータスには、
  再リンクされたルールと一致しないままのルールの数が表示されます。
- アラートのインポートファイルは 1 MiB に制限されます。

別のコンピューターへ移行する場合は、最初にアプリケーション設定をインポートし、次にアラートルールを
インポートします。アラートを後からインポートすると、ルールを新しいサブスクリプション ID にシンボルで
再接続できます。

### 構成ファイルを直接編集する

アプリ設定にある **現在のアプリ構成を編集 (Edit Current App Config)** と **現在のアラートルールを編集
(Edit Current Alert Rules)** は、システムで `.json` に関連付けられたテキストエディターで使用中の
JSON ファイルを開きます。これは上級ユーザー向けです。SmartTicker の各ウィンドウでも、危険を伴わずに
同じ設定を扱えます。

どちらのボタンも、最初に現在のファイルをエクスポートするよう確認を表示します。必ずエクスポートして
ください。手動編集でファイルが壊れる可能性があり、元に戻す機能はありません。

- **既存の構成をエクスポート... (Export existing config...)** は現在のファイルを保存し、同じ確認画面へ
  戻ります。
- **テキストエディターで開く (Open in text editor)** は使用中のファイルを開きます。
- **キャンセル (Cancel)** は何も変更しません。

SmartTicker はファイルを監視し、エディターで保存されるとすぐに再読み込みします。

- 有効なファイルは直ちに適用され、再起動せずにティッカーが更新されます。
- 不正な JSON、スキーマ違反、その他の検証エラーは拒否されます。実行中の構成は変更されず、
  アプリ設定ウィンドウに問題が表示されます。
- 編集が拒否された後はファイルを修正するか、**設定をインポート... (Import settings...)** または
  **アラートルールをインポート... (Import alert rules...)** で有効なエクスポートを復元します。
- 別のプログラムによってロックされたままのファイルは短時間再試行され、その後エラーとして報告されます。

アラートルールファイルの編集も同じ規則に従います。2 つのファイルは独立しているため、
アプリケーション設定には影響しません。

## アラートルール

右クリックメニューから **アラート (Alerts)** を開きます。ルールは価格の更新に成功するたびに評価され、
プレマーケット値や時間外取引値ではなく、通常価格だけを監視します。

### ルールを作成する

1. 構成済みの **株価 (Quote)** を選択します。同じシンボルの項目も別々のままです。
2. **条件 (Condition)** を選択し、`250.50` のようなカルチャに依存しない小数形式で数値しきい値を
   入力します。
3. 必要に応じて **有効開始日時 (Active from)** を選択します。すぐに有効にするには空のままにします。
4. **無期限 (Never expires)** をオンのままにするか、オフにして有効期限を選択します。
5. **ルールを追加 (Add rule)** を選択します。

使用できる比較は次のとおりです。

| 選択肢 | 意味 |
| --- | --- |
| `LessThan` | 価格がしきい値より `<`。 |
| `LessThanOrEqual` | 価格がしきい値以下 `<=`。 |
| `GreaterThan` | 価格がしきい値より `>`。 |
| `GreaterThanOrEqual` | 価格がしきい値以上 `>=`。 |
| `EqualTo` | 価格がしきい値と正確に等しい。 |
| `NotEqualTo` | 価格がしきい値と異なる。 |

開始境界はその時刻を含みます。有効期限の境界もその時刻を含みます。期限を過ぎるとルールは発動しません。
SmartTicker は開始より前の有効期限を拒否します。

### ルールが発動したとき

有効でスケジュール内のルールは、条件が false から true に変わったときに 1 回発動します。条件が true の
ままである間、更新のたびに通知することはありません。価格が条件から外れるとルールが再設定され、再び
条件内に入ったときに発動できます。

ルールを編集するか、無効にしてから再度有効にした場合も再設定されます。そのため、最新の通常価格が
すでに条件を満たしていると、有効にしたルールが直ちに発動する場合があります。取得に失敗した価格や
欠落した価格ではルールは発動しません。

1 つ以上のルールが発動すると:

- 対象の価格項目は、設定された時間だけ、設定済みのアラート点滅色と黒を交互に表示します。
  既定の点滅色はマゼンタ (`#FF00FF`) です。
- **ブザー (Buzz)** が有効な場合、SmartTicker は設定済みのブザーシーケンスを再生します。
- アラートメッセージは、1 つのルールを示すか、同時に発動したルール数を報告します。
- アラートの強調表示中もティッカーのスクロールは続きます。

### アラート出力設定

| 設定 | 範囲 | 既定値 |
| --- | --- | --- |
| **ブザー (Buzz)** | オンまたはオフ | オン |
| ブザー回数 (Buzz count) | 1 から 20 | 15 |
| **点滅時間 (Blink for)** | 5 から 900 秒、15 秒単位 | 60 秒 |

ブザーを無効にしても視覚アラートは有効なままです。同じ評価で複数のルールが発動した場合、SmartTicker は
その評価に対して設定済みのブザーシーケンスを 1 回開始します。**アプリ設定 > 外観
(App Settings > Appearance)** の **アラート点滅 (Alert blink)** で変更します。これはアプリケーションの
外観設定であるため、独立したアラートルールファイルではなく、設定のエクスポート/インポートに含まれます。

### 構成済みルールを管理する

- **編集 (Edit)** はルールをフォームへ読み込みます。保存するには **ルールを更新 (Update rule)**、
  変更しない場合は **キャンセル (Cancel)** を選択します。
- **無効化 (Disable)** はルールを保持したまま一致を停止します。**有効化 (Enable)** はルールを
  再設定し、最新の通常価格に対して評価します。
- **削除 (Remove)** はルールを削除します。
- 一覧には、有効状態、シンボル、条件の概要、スケジュールが表示されます。

アラートルールの変更とアラート出力設定は自動的に保存されます。

## ローカルファイルとプライバシー

SmartTicker は構成をローカルに保存し、開発者サービスとは同期しません。

Windows の既定ファイルは次のとおりです。

```text
%LocalAppData%\SmartTicker\settings.json
%LocalAppData%\SmartTicker\alerts.json
```

Linux では、.NET は現在のユーザーのローカルアプリケーションデータディレクトリを使用します。通常は
次の場所です。

```text
~/.local/share/SmartTicker/settings.json
~/.local/share/SmartTicker/alerts.json
```

### 分離したデータディレクトリを使用する

高度な診断とテスト実行では、SmartTicker を起動する前に `SMARTTICKER_DATA_DIRECTORY` を設定できます。
値が空でない場合、両方のファイルは解決されたディレクトリに `settings.json` および `alerts.json` として
直接配置され、そのプロセスでは上記のプラットフォーム既定値が使用されません。絶対パスを推奨します。
また、書き込み可能であることを確認してください。

PowerShell の例:

```powershell
$env:SMARTTICKER_DATA_DIRECTORY = 'D:\SmartTicker-Profile'
& 'C:\Program Files\SmartTicker\SmartTicker.Desktop.exe'
```

Linux シェルの例:

```bash
SMARTTICKER_DATA_DIRECTORY="$HOME/.local/share/SmartTicker-Test" smartticker
```

プロセスを起動する前に変数を設定します。SmartTicker は既定のプロファイルを選択したディレクトリへ
コピーしないため、空のディレクトリでは空の構成から開始します。同じディレクトリを指定した複数の
インスタンスは、互いに保存した編集を検出できます。バックアップとプロファイル移行には、通常の設定と
アラートルールのエクスポート/インポートコマンドを使用します。

アラートウィンドウには、使用中のアラートファイルの正確なパスが表示されます。書き込みには一時ファイルと
その後の置換が使用されるため、途中まで書き込まれたファイルが現在の構成として扱われることはありません。

SmartTicker には、アカウント、テレメトリ、分析、広告、クラウド同期はありません。SmartTicker がソースを
要求すると、そのウェブサイトは IP アドレスなどの通常のネットワーク情報を受け取ります。ヘルプを開くと
GitHub から生のガイドを要求します。詳細については、リポジトリの `PRIVACY.md` をお読みください。

各ソース URL とセレクターを、ウェブサイトの規約、ライセンス、robots ディレクティブ、および適用法に
従って使用する責任はユーザーにあります。

## トラブルシューティング

### 株価が利用不可または価格なしと表示される

ソース要求は 20 秒後にタイムアウトします。その株価に以前の正常なスナップショットがある場合、更新に
失敗しても表示は維持されます。それ以外の場合、後の更新に成功するまで **利用不可 (Unavailable)** と
表示されます。セレクターを変更する前に、検証または更新エラーを確認してください。

1. **株価... (Quotes...)** を開き、項目を編集して、完全な URL (Full URL) を確認します。
2. **価格 (Price)** が選択されていることを確認します。
3. 求められた場合はウェブサイトを承認します。
4. **URL を検証 (Validate URL)** を選択し、正確な結果を確認します。
5. **価格を検出 (Discover price)** を実行するか、ページの静的 HTML を調べてセレクターを更新します。
6. ページが JavaScript、認証、または SmartTicker で安全に処理できない同意を必要としていないか
   確認します。
7. HTTP 403、429、robots の制限、サイトの自動アクセスポリシーを遵守してください。

### プレマーケットまたは時間外取引のデータがない

- 対応する市場セッションが有効でない可能性があります。
- セッション値が存在しないとき、ページがそのセッション要素を省略する場合があります。
- プレマーケットセレクターがプレマーケット要素を、時間外セレクターが取引終了後要素を対象としている
  ことを確認します。
- ウェブサイトのマークアップが変更されている可能性があるため、対応する検出コマンドを再実行します。

### ニュースが空である

- **ニュース (News)** が選択されていることを確認します。
- ソースを検証し、**ニュースを検出 (Discover news)** を実行します。
- セレクターが表示可能な見出しテキストを持つリンクを返すことを確認します。
- ニュース要求が失敗またはタイムアウトした場合でも、以前に正常取得した見出しがあれば維持されます。
  正常な結果が一度もないソースは、後の時間枠で成功するまで空のままです。
- 見出しは、このセッション用に設定された繰り返し上限に達すると消えます。
- 静的ニュースでは、目的の株価が **ニュースの表示対象 (Show news for)** でオンになっていることを
  確認します。

### セレクター検出で何も見つからない

検出機能はダウンロード済みの静的 HTML だけを読み取ります。ページの JavaScript が後から作成する値は
確認できません。検証済みのセレクターを手動で入力するか、静的ページ/フィードを選択するか、互換性のある
公開ページを通じて承認済みの文書化された API を使用してください。

### アラートが発動しない

- 関連付けられた株価がまだ存在し、価格を収集し、通常価格を正常に取得していることを確認します。
- ルールが有効 (Enabled) で、開始/有効期限のスケジュール内にあることを確認します。
- 比較としきい値を確認します。`EqualTo` には小数値の正確な一致が必要です。
- 常に true の条件は 1 回だけ発動することに注意してください。ルールを編集または再度有効にした場合を
  除き、再発動するには一度 false になる必要があります。
- プレマーケット価格と時間外取引価格はアラートルールを発動しません。

### SmartTicker を移動またはサイズ変更できない

- 左側の帯にある縦の点のグリップからのみ移動します。
- 辺または角からサイズを変更します。辺をつかみにくい場合は右下の表示マークを使用します。
- ティッカーの内容は、意図的に移動領域にはなっていません。

### 静的グループまたは値が想定と異なる

- **株価... (Quotes...)** を開き、各項目のグループ (Group) 値を確認します。
- **株価グループ... (Quote groups...)** を開いてグループ定義を管理し、各株価の現在の関連付けを
  確認します。
- グループが空の項目は **グループなし (Ungrouped)** に表示されます。
- **変化量 (Chg)** は Last と Chg% から計算され、ページから独立して抽出されるものではありません。
  パーセントを利用できない場合は `—` のままです。
- 上下ボタンで項目を並べ替え、グループと行の順序を変更します。
- タイル見出しの点線ハンドルをドラッグしてグループ全体を移動します。別のタイルの左半分にドロップすると
  その前に、右半分にドロップするとその後に配置されます。
- SmartTicker が一時停止していないときに **価格を今すぐ更新 (Refresh prices now)** を選択して
  テーブルを更新します。

### ヘルプのテキストが書式設定されない、またはナビゲーションが動作しない

- ヘルプウィンドウには、Markdown の記号ではなく、書式設定された見出し、段落、リスト、テーブル、
  リンク、コードブロックが表示される必要があります。
- 左側の **このページの内容 (On this page)** を使用して主要セクションへ移動します。クイック
  ナビゲーションテーブルのリンクでも文書内をスクロールできます。
- ヘルプを閉じて開き直すか、**言語 (Language)** を変更して、対応する公開済みガイドを
  要求します。取得されるまで、SmartTicker はインストール済みアプリケーションに
  組み込まれた書式設定済みガイドを表示します。

### オンラインヘルプを利用できない、または内容が古い

- ヘルプを閉じて再度開き、公開済みガイドをもう一度要求します。
- このガイドの冒頭付近に示された GitHub の生アドレスをブラウザーで開き、公開ファイルを直接確認します。
- 要求が失敗するか空のファイルが返された場合、SmartTicker は組み込みガイドを使用します。
- オンラインの変更は、`HELPME.md` または対応する
  `help/HELPME.<language-code>.md` がリポジトリの `main` ブランチへ公開された後にのみ
  表示されます。
